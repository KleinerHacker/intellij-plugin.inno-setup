IsScriptCollector

class IsScriptCollector(project: Project)

Finds the .iss scripts in a project that should be compiled on build: the top-level scripts, i.e. those not pulled in via #include from another .iss. Include fragments would fail to compile standalone, so they are excluded.

The #include extraction (parseIncludes) is a pure helper for unit testing.
