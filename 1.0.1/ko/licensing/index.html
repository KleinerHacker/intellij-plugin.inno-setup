    Inno Setup

    Copyright (C) 1997-2026 Jordan Russell. All rights reserved.
Portions Copyright (C) 2000-2026 Martijn Laan.

    Inno Setup은 jrsoftware.org가 자체 허용적 라이선스로 공개한 무료 설치 관리자 빌더입니다. 전체 라이선스 본문은 Inno Setup 저장소에서 확인할 수 있습니다.

    Inno Setup의 어떤 부분도 이 플러그인과 함께 배포되지 않습니다. Inno Setup 컴파일러(ISCC.exe)는 별도로 설치해야 하며, 플러그인 설정에서 지정한 설치 디렉터리에서 호출됩니다.

    파생 문서

    코드 완성, 인라인 문서, 검증에 사용되는 섹션, 지시문, 매개변수, 상수, 언어 코드, 전처리기 설명은 공식 Inno Setup 문서에서 파생된 것이며 Jordan Russell과 Martijn Laan이 보유한 저작권의 적용을 받습니다.

    예제 스크립트

    통합 테스트 스위트는 공식 Inno Setup 예제 스크립트로 플러그인을 검증합니다. 이 스크립트들은 이 저장소의 일부가 아니며, 테스트 실행 전에 고정된 jrsoftware/issrc 태그에서 빌드 디렉터리로 다운로드되고 실행 후 다시 삭제됩니다.

    상표 및 면책 조항

    이 플러그인은 비공식 커뮤니티 개발 플러그인입니다. Jordan Russell, Martijn Laan 또는 jrsoftware.org와 제휴 관계가 없으며 이들의 보증이나 후원을 받지 않습니다. "Inno Setup" 및 Inno Setup 로고는 각 소유자의 자산이며, 이 플러그인이 지원하는 소프트웨어를 가리키기 위해서만 사용됩니다.

    플러그인 로고는 독자적으로 제작된 것이며 Inno Setup 로고에서 파생되지 않았습니다.

    종속성

    번들된 모든 서드파티 종속성의 라이선스는 생성된 종속성 보고서에 나열되어 있습니다.
