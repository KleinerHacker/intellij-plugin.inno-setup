    コードスタイル

    プラグインは コードの整形（Ctrl+Alt+L）で .iss / .isl スクリプトを整形します。 ルールは 設定 ▸ エディター ▸ コードスタイル ▸ Inno Setup にあり、既定ではすべて有効です。

    ルール

    ルール 効果 例
    セクション間はちょうど 1 行の空行 2 つの [Section] ブロック間の空きを空行 1 行に統一（または挿入）します。 …value⏎⏎⏎[Files] → …value⏎⏎[Files]
    セクションの角括弧内にスペースを入れない セクション名の角括弧を詰めます。 [ Setup ] → [Setup]
    ディレクティブの = の前後にスペース Key = Value ディレクティブの = の両側に 1 つずつスペースを入れます。 AppName=My App → AppName = My App
    パラメータの : の後にスペース Key: Value パラメータの : の前は空けず、後に 1 つスペースを入れます。 DestDir:"{app}" → DestDir: "{app}"
    パラメータ間の ; の後にスペース パラメータ対を区切る ; の前は空けず、後に 1 つスペースを入れます。 "a" ;DestDir → "a"; DestDir
    キーの前に先頭スペースを入れない キー / パラメータ / セクション見出しの行を 0 桁目から始めます。 ····AppName = A → AppName = A
    算術演算子の前後にスペース プリプロセッサ式の + - * / %（二項演算子のみ）の両側にスペースを入れます。 #define X 2+3*4 → #define X 2 + 3 * 4
    行継続の \ の前にスペース 継続されたプリプロセッサ行の末尾 \ の前に必ずスペース 1 つを置き、その後ろには空白を残しません。 #define X 1···\·· → #define X 1 \
    継続行をインデントする 継続されたディレクティブの後続行を言語の継続インデントに揃えます。 #define X 1 + \⏎2 → #define X 1 + \⏎········2

    各ルールは設定ページで個別に無効化できます。=・:・;・角括弧・先頭スペースおよび 2 つの継続オプションは スペース (Spacing)、空行のオプションは 空行 (Blank Lines) にあります。

    変更されない箇所

    • [Code] セクション（Pascal Script）とそれ以降のすべて — インデントとレイアウトは保持されます。
    • 値そのもの — 区切り文字の周囲の空白のみを整え、値のテキストは変更しません。
    • 単項符号（-3）、識別子やバージョン文字列内の -、および引用符付き文字列の内容は算術演算子として扱いません。
    • 行継続は行末と同じ扱いです。空白がその境界を越えて移動することはないため、複数行に分かれたディレクティブのレイアウトは保たれます。正規化されるのは \ の前のスペースと継続行のインデントだけです。

    関連項目

    エディター表示のオプションは エディター、インストールディレクトリとバージョン検証は 設定 を参照してください。
