class IsEditorSettingsConfigurable : SearchableConfigurable

IDE-wide editor settings sub-page ("Inno Setup | Editor") for how .iss scripts are presented in the editor. Currently offers the toggle for the #include content inlay hints. Stored application-wide in IsSettingsState via IsSettingsService.
