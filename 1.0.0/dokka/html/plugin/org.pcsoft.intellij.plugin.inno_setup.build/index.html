IsBuildConsoleService
Link copied to clipboard
class IsBuildConsoleService(project: Project) : Disposable

Owns the single ConsoleView that shows Inno Setup compiler output, hosted in the "Inno Setup" tool window. Uses only public platform APIs (console builder, tool window manager, content factory) — no internal Build-tool-window/event APIs. The console is created lazily on the EDT and disposed with the project (this service). In headless/unit-test mode no UI is created and all output is dropped.

IsBuildOutputConsoleFolding
Link copied to clipboard
class IsBuildOutputConsoleFolding : ConsoleFolding

Folds the indented detail lines of the ISCC compiler output in the "Inno Setup" tool-window console (e.g. the Reading file: … / Messages in script file lines below a \[Languages] section). Consecutive indented lines are merged by the platform into a single, collapsed-by-default region whose placeholder shows the number of hidden lines.

class IsCompilerService(project: Project)

Compiles Inno Setup scripts with ISCC and streams the output into the dedicated "Inno Setup" tool window console (IsBuildConsoleService), reporting the final result as a balloon notification. Shared by the project-build hook (compileProject) and the per-file context-menu action (compileScript).
