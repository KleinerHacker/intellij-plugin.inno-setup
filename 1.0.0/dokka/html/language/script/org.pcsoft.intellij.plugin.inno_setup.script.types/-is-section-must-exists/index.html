IsSectionMustExists

data class IsSectionMustExists(val except: IsSectionSpecExceptions? = null)

Marks a file/directory typed value as having to exist on the build machine at compile time.

The mere presence of the mustExists key enables the check — in the spec YAML the usual form is the bare mustExists: with no value. An absent key means the value is a target/runtime path that is only validated for invalid path characters.
