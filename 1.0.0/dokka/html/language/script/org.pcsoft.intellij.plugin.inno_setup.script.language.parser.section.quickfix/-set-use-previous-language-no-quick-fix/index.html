SetUsePreviousLanguageNoQuickFix

class SetUsePreviousLanguageNoQuickFix(file: IsScriptFile) : IntentionAction

Sets UsePreviousLanguage in \[Setup] to no, the value Inno Setup requires when the script declares only a single language. Replaces an existing value, inserts the directive into an existing \[Setup], or creates a \[Setup] section if none is present.
