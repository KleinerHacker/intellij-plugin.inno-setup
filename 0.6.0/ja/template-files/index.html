    Inno Setup テンプレートファイル

    インストーラースクリプト（.iss）と言語ファイル（.isl）に加えて、このプラグインは Inno Setup テンプレートファイル（ .ist）をサポートします。テンプレートは再利用可能な自由テキストの断片であり、ISPP の #include ディレクティブを通じてスクリプトに取り込まれることを意図しています。共通のセクション、ディレクティブ、プリプロセッサー定義を個々のスクリプトから切り出し、複数のインストーラー間で共有できます。

    テンプレートとは

    .ist ファイルは自由テキストです。.iss や .isl ファイルとは異なり、必須の構造を持たず、単独のスクリプトとして検証されることもありません：

    • セクション全体（[Files]、[Registry]…）、部分的なセクション、ばらばらのディレクティブ行、ISPP プリプロセッサーディレクティブ（ #define、#include…）、またはこれらの任意の組み合わせを含めることができます。
    • 実際の .iss スクリプトでは無効になるような内容を含むことさえできます。テンプレートは完全なインストーラーではなく構成要素にすぎないからです。そのためプラグインは .ist ファイルで解析エラーや検証警告を一切報告しません。
    • その意味は、ホストスクリプトに取り込まれて初めて、周囲の .iss 内容のコンテキストの中で解釈されたときにのみ確定します。

    これは Inno Setup プリプロセッサー（ISPP）が #include のターゲットを扱う方法を反映しています：取り込まれたテキストはそのままスクリプトに継ぎ合わされるため、断片の正しさは常にそれが取り込まれる場所次第です。

    テンプレートの使用

    テンプレートは #include を通じて利用されます。ファイル拡張子は ISPP にとって無関係なので、.ist テンプレートは他のどのファイルとも全く同じように取り込まれます：

    ; main.iss
[Setup]
AppName=My Program
AppVersion=1.5

#include "common-files.ist"
#include "registry-defaults.ist"

    ; common-files.ist （テンプレート、自由テキスト）
[Files]
Source: "readme.txt"; DestDir: "{app}"
Source: "license.txt"; DestDir: "{app}"

    ホストスクリプトが解析されると、プラグインは #include を解決し、テンプレートのセクションを有効スクリプト（main.iss のインクルードを完全に解決したビュー）にマージします。ホストと取り込まれたテンプレートの同名セクションは 1 つのブロックに統合されるため、上記の例は [Files] のエントリが main.iss の中に直接書かれていたかのように振る舞います。

    テンプレートは他のテンプレート（やスクリプト）を推移的に取り込むことができます。インクルードの循環は検出され、安全に打ち切られます。

    編集機能

    構文ハイライト

    テンプレートは専用のハイライターを使用し、自由テキストの断片の中でもおなじみの Inno Setup 構造が読みやすく保たれます：

    • セクションヘッダー（[Files]、[Registry]…）は構造マーカーとしてハイライトされます
    • プリプロセッサー行（#define、#include…）は唯一の構造化要素として認識され、完全な ISPP 言語インジェクションを通じてハイライトされます（下記参照）

    プリプロセッサーインジェクション

    テンプレート内のすべての #… 行は、.iss/.isl ファイルと全く同様に注入された ISPP 断片を持ちます。それらの行の中では、 #define、#include、式、組み込み関数に対する補完・参照・インラインドキュメントなど、完全なプリプロセッサー言語サポートが得られます。

    セクション名補完

    [ を入力すると補完ポップアップが開き、既知のすべての Inno Setup セクション名 が提示されます。テンプレートはファイルタイプやバージョンによるフィルタリングのない自由テキストなので、常にセクションの全集合が提案されます（ .iss/.isl のコンテキスト制限付きリストとは異なります）。候補を受け入れると閉じ ] が自動的に挿入されます。

    括弧マッチング

    [ ]（構造的なセクション括弧）と ( ) に対してマッチングが提供されるため、テンプレート断片内のナビゲーションと釣り合わせはスクリプトと同じように機能します。

    インクルードパス補完とナビゲーション

    #include "…" ディレクティブ内では、.ist テンプレートが他の取り込み可能なファイルと並んで補完候補として提示され、パスはテンプレートファイルに解決されて 定義へ移動ナビゲーションが可能になります。

    テンプレートが意図的に持たないもの

    .ist ファイルは意図的に非構造化の断片であるため、いくつかのスクリプト専用機能はオフになっています：

    • 検証／アノテーターなし — 壊れた、またはコンテキスト外の Inno Setup 内容が ERROR や WARNING のハイライトを生むことは決してありません。
    • 構造ビューなし — テンプレートには表示すべき保証されたセクションツリーがありません。

    これらの機能はホストの .iss/.isl スクリプトでは引き続き利用でき、そこではテンプレートの内容が実際のインクルード解決済みのコンテキストの中で解析されます。

    テンプレートの作成

    IDE の新規ファイルメニューから 新規 → Inno Setup テンプレート を使用します。テンプレートは自由テキストなので、ダイアログはファイル名のみを尋ね、空の .ist ファイルを作成します。内容のひな形は生成されません。
