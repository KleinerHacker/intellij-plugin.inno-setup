# Architecture

All language information of Inno Setup for the installer is stored in `language/script/src/main/resources/spec/is-lang-code.yaml`.
This file is based on the schema file `language/script/src/main/resources/spec/is-lang-code.json`. Both files must be kept in sync.

The documentation is based on: `https://jrsoftware.org/ishelp/`
