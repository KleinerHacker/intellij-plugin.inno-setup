# Architecture

All constant information of Inno Setup for Inno Setup scripts is stored in `language/script/src/main/resources/spec/is-const.yaml`.
This file is based on the schema file `language/script/src/main/resources/spec/is-const.json`. Both files must be kept in sync.

The documentation is based on: `https://jrsoftware.org/ishelp/`
