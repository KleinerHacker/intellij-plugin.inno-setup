# Architecture

All preprocessor constants, functions, macros and so on of Inno Setup for use in Inno Setup scripts are stored in `language/preprocessor/src/main/resources/spec/is-preprocessor.yaml`.
This file is based on the schema file `language/preprocessor/src/main/resources/spec/is-preprocessor.json`. Both files must be kept in sync.

The documentation is based on: `https://jrsoftware.org/ishelp/`
