IsPreprocessorMacroParameterElement

class IsPreprocessorMacroParameterElement(directive: IsPreprocessorDirective, parameterName: String, offsetInDirective: Int) : FakePsiElement

The declaration of a function-like macro parameter (#define M(int A, B = 10) …) as a navigable, renameable element.

ISPP declares parameters inside the free-form value text of the #define, so there is no PSI node of its own to point at. This element stands in for the declaration: it is anchored at the parameter name inside the owning directive, which gives navigation a target, Find Usages an owner and rename an element to work on — all confined to that single directive, because a macro parameter is not visible anywhere else.
