RecordingAnnotationBuilder

class RecordingAnnotationBuilder(severity: HighlightSeverity, message: String?, sink: (RecordedProblem) -> Unit) : IsAnnotationDraft

An IsAnnotationDraft that records nothing visually: its fluent calls are no-ops returning this. Only the range, an optional explicit message and the file-level flag are tracked. On create a non-file-level ERROR or WARNING with a known range and message is handed to sink; everything else (highlighting/INFORMATION, weak warnings, file-level problems) is discarded.

Used to replay the real annotators over an in-memory effective script and harvest their problems without touching any editor markup. See IsEffectiveScriptProblems. Deliberately implements only the plugin-owned IsAnnotationDraft façade — never the platform's @NonExtendable AnnotationBuilder.
