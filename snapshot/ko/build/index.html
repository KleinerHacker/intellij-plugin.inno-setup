    빌드 통합

    이 플러그인은 Inno Setup의 명령줄 컴파일러 ISCC를 IDE에 직접 통합하여 편집기를 떠나지 않고 .iss 스크립트를 컴파일할 수 있습니다. 빌드 기능을 사용하기 전에 빌드, 실행, 배포 → Inno Setup → 일반에서 Inno Setup 설치 디렉토리가 구성되어 있는지 확인하세요(설정 참조).

    빌드 트리거

    컨텍스트 메뉴 작업

    프로젝트 뷰 또는 편집기 탭에서 .iss 파일을 마우스 오른쪽 버튼으로 클릭하고 Build Inno Setup Script를 선택합니다. 이 작업은 .iss 파일에 대해서만 표시되며, 다른 스크립트에 #include된 스크립트에 대해서는 비활성화됩니다(설명 툴팁 포함)——해당 파일은 최상위 부모를 통해 빌드해야 합니다.

    프로젝트 빌드 시 자동 빌드

    빌드 설정에서 프로젝트 빌드 시 .iss 파일 컴파일이 활성화되면 IDE가 프로젝트를 빌드할 때마다(예: 빌드 → 프로젝트 빌드 또는 망치 아이콘 사용) 프로젝트의 모든 최상위 .iss 스크립트가 자동으로 컴파일됩니다. 다른 스크립트에 포함된 스크립트는 자동으로 건너뜁니다.

    빌드 출력 콘솔

    빌드 결과는 전용 Inno Setup 노드 아래 빌드 도구 창에 나타납니다. 컴파일된 각 스크립트는 이름과 오류 또는 경고 수를 표시하는 자체 자식 노드를 갖습니다.

    콘솔 출력

    오른쪽 패널에는 원시 ISCC 출력이 한 줄씩 표시됩니다——진행 메시지, 섹션 파싱 참고사항, 컴파일러 진단:

    줄 유형 모양 예시
    진행 일반 흰색 텍스트 Parsing [Files] section, line 22
    오류 빨간색 텍스트 Error on line 22 in C:\...\demo.iss: Source file "..." not found
    경고 노란색 텍스트 Warning on line 5 in C:\...\demo.iss: ...

    구조화된 섹션 출력 및 폴딩

    ISCC 출력은 하나의 긴 평면 로그 대신 구조화된 형태로 표시됩니다:

    • 섹션 노드 — 동일한 Inno Setup 섹션에 속하는 연속된 출력 줄 (Parsing [Setup] section …, Parsing [Languages] section … 등)은 빌드 트리의 단일 노드로 그룹화되며, 섹션 이름과 접힌 줄 수로 레이블이 지정됩니다(예: [Setup] (8)). 섹션 노드는 전체 빌드 상태와 관계없이 항상 표시되며, 내용에 따라 INFO, WARN, ERROR 심각도를 가집니다.
    • 콘솔 폴드 — 콘솔에서 들여쓰기된 세부 줄([Languages] 아래의 Reading file: … / Messages in script file 등)은 기본적으로 접혀 있으며, 자리 표시자에 숨겨진 줄 수가 표시됩니다. 폴드를 펼치면 개별 줄을 확인할 수 있습니다.

    이로써 출력이 간결하게 유지되어 섹션당 한 항목을 한눈에 볼 수 있고, 필요한 곳에서만 세부 정보를 펼칠 수 있습니다.

    탐색 가능한 오류 링크

    파일 위치를 포함하는 오류 및 경고 줄에는 클릭 가능한 line XX 하이퍼링크가 있습니다. 클릭하면 참조된 .iss 파일이 열리고 보고된 줄과 열로 커서가 직접 이동하여 스크립트를 수동으로 검색하지 않고도 문제를 수정할 수 있습니다.

    빌드 트리

    빌드 도구 창 왼쪽의 트리에 결과가 요약됩니다:

    • 스크립트 노드의 빨간색 오류 아이콘은 컴파일러 오류가 하나 이상 있음을 나타냅니다.
    • 노란색 경고 아이콘은 경고는 있지만 오류는 없음을 나타냅니다.
    • 개별 문제 항목이 자식 노드로 나열되며 클릭하면 소스 위치로 이동합니다.

    출력 모드

    컴파일된 설치 프로그램의 출력 위치는 빌드 설정을 통해 프로젝트별로 제어할 수 있습니다:

    모드 ISCC 플래그 설명
    스크립트에 정의된 대로(script) (없음) [Setup]의 OutputDir을 그대로 사용
    프로젝트 빌드 디렉토리로(기본값) /O 상대 OutputDir을 프로젝트 빌드 폴더(out/target/build)로 리디렉션
    드라이 빌드 — 유효성 검사만, 출력 없음 /O- 설치 프로그램 파일 없이 스크립트 유효성 검사. CI 검사에 유용
