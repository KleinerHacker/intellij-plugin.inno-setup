IsPreprocessorExprValueResolver
Link copied to clipboard
class IsPreprocessorExprValueResolver(defines: List<IsPreprocessorExprDefineInfo>, functionMacros: List<IsPreprocessorExprFunctionMacroInfo> = emptyList(), arrayElements: List<IsPreprocessorExprArrayElementInfo> = emptyList())

Computes the static value of a #define expression, resolving references to other simple #defines and calls to function-like macros recursively — so #define A 10 / #define B A + 5 lets B evaluate to 15, and #define f(x) "a" + x / #define C f("b") lets C evaluate to "ab".
