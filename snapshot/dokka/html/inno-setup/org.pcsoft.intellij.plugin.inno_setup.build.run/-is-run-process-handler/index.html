IsRunProcessHandler

class IsRunProcessHandler(project: Project, config: IsRunConfiguration) : ProcessHandler

A ProcessHandler that drives the two-stage pipeline:

  1. Hand off to the build (IsCompilerService), which decides whether a recompile is needed and streams its output into the Build tool window.

  2. Launch the generated installer (or uninstaller).

Stage 2 output is forwarded to the attached com.intellij.execution.ui.ConsoleView.
