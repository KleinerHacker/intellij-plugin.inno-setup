var persistentTempOutputDir: String

Hidden (not shown in the editor) — persistent temporary output directory, used only when the project is configured for org.pcsoft.intellij.plugin.inno_setup.build.IsBuildOutputMode.DRY (which would otherwise produce no real setup.exe). Stays attached to the run configuration so the generated installer can be reused across runs.
