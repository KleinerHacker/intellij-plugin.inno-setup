IsSectionCodeStyleSettingsProvider

class IsSectionCodeStyleSettingsProvider : LanguageCodeStyleSettingsProvider

Contributes the Settings ▸ Editor ▸ Code Style ▸ Inno Setup page and — via createCustomSettings — the IsSectionCodeStyleSettings instance the formatter reads. It lives in :language:script (rather than in :plugin) because the custom settings are a language-level concern: the formatter and its tests depend on them, so they must be registered by the same fragment that registers the formatter itself.

Every option (each defaulting to on) is shown as a check box under the Spacing and Blank Lines tabs; the live preview is fed with a representative script sample.
