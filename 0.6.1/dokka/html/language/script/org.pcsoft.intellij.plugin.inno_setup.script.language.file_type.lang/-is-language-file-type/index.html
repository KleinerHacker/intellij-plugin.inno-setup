IsLanguageFileType

class IsLanguageFileType : LanguageFileType

File type for Inno Setup language files (.isl). Bound to the existing IsScriptLanguage so all ISS language extensions (highlighting, completion, navigation, …) apply automatically; only the allowed sections differ (enforced in language/isl/parsing).
