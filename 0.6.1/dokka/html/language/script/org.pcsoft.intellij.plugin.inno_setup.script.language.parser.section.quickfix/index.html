class ReplaceSeparatorQuickFix(holderElement: PsiElement, tokenType: IElementType, wrong: String, replacement: String) : IntentionAction

Replaces the wrong key/value separator of a single entry with the one its section expects: ':' → '=' inside a directive section, or '=' → ':' inside a parameter section. holderElement is the pair/entry that owns the separator token; tokenType is the wrong separator's token type and replacement the correct character.
