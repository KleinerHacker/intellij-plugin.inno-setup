IsPreprocessorFile

class IsPreprocessorFile(viewProvider: FileViewProvider) : PsiFileBase

PSI file root of an injected ISPP fragment.

The file is created by the ISPP parser definition when IsPreprocessorInjector injects the language into an IsSectionPreprocessorLine host. There are no standalone .ispp files; see IsPreprocessorFileType for why this injection-only language still needs a file type.
