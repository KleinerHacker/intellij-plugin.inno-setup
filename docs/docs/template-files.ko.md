# Inno Setup 템플릿 파일

설치 프로그램 스크립트(`.iss`)와 언어 파일(`.isl`) 외에도, 이 플러그인은 **Inno Setup 템플릿 파일**(`.ist`)을 지원합니다. 템플릿은 ISPP의 `#include` 지시문을 통해 스크립트에 가져오기 위한 재사용 가능한 자유 텍스트 조각입니다. 공통 섹션, 지시문 또는 전처리기 정의를 개별 스크립트에서 분리하여 여러 설치 프로그램 간에 공유할 수 있게 해줍니다.

---

## 템플릿이란

`.ist` 파일은 **자유 텍스트**입니다. `.iss` 및 `.isl` 파일과 달리 필수 구조가 없으며 독립 실행형 스크립트로 검증되지 않습니다:

- **전체 섹션**(`[Files]`, `[Registry]`…), **부분 섹션**, 흩어진 지시문 줄, ISPP 전처리기 지시문(`#define`, `#include`…), 또는 이들의 임의 조합을 포함할 수 있습니다.
- 실제 `.iss` 스크립트에서는 유효하지 않을 내용까지도 포함할 수 있습니다. 템플릿은 완전한 설치 프로그램이 아니라 구성 요소일 뿐이기 때문입니다. 따라서 플러그인은 `.ist` 파일에서 **파싱 오류나 검증 경고를 결코 보고하지 않습니다**.
- 그 의미는 호스트 스크립트에 포함되어 주변 `.iss` 내용의 컨텍스트에서 해석될 때 비로소 결정됩니다.

이는 Inno Setup 전처리기(ISPP)가 `#include` 대상을 다루는 방식을 반영합니다: 포함된 텍스트는 있는 그대로 스크립트에 이어 붙여지므로, 조각의 정확성은 항상 그것이 포함되는 위치에 달려 있습니다.

---

## 템플릿 사용

템플릿은 `#include`를 통해 사용됩니다. 파일 확장자는 ISPP와 무관하므로 `.ist` 템플릿은 다른 어떤 파일과도 정확히 동일하게 포함됩니다:

```ini
; main.iss
[Setup]
AppName=My Program
AppVersion=1.5

#include "common-files.ist"
#include "registry-defaults.ist"
```

```ini
; common-files.ist (템플릿, 자유 텍스트)
[Files]
Source: "readme.txt"; DestDir: "{app}"
Source: "license.txt"; DestDir: "{app}"
```

호스트 스크립트를 분석할 때 플러그인은 `#include`를 해석하고 템플릿의 섹션을 **유효 스크립트**(`main.iss`의 포함이 완전히 해석된 뷰)에 병합합니다. 호스트와 포함된 템플릿의 동일한 이름의 섹션은 하나의 블록으로 통합되므로, 위 예제는 `[Files]` 항목이 `main.iss` 안에 직접 작성된 것처럼 동작합니다.

템플릿은 다른 템플릿(또는 스크립트)을 전이적으로 포함할 수 있습니다. 포함 순환은 감지되어 안전하게 끊어집니다.

## 편집 기능

### 구문 강조

템플릿은 전용 강조기를 사용하여 익숙한 Inno Setup 구조가 자유 텍스트 조각에서도 읽기 쉽게 유지되도록 합니다:

- **섹션 헤더**(`[Files]`, `[Registry]`…)는 구조 표시로 강조됩니다
- **전처리기 줄**(`#define`, `#include`…)은 유일한 구조화 요소로 인식되며 전체 ISPP 언어 주입을 통해 강조됩니다(아래 참조)

### 전처리기 주입

템플릿의 모든 `#…` 줄은 `.iss`/`.isl` 파일과 정확히 동일하게 **주입된 ISPP 조각**을 가집니다. 이러한 줄 안에서는 `#define`, `#include`, 표현식, 내장 함수에 대한 자동 완성, 참조, 인라인 문서 등 완전한 전처리기 언어 지원을 받습니다.

### 섹션 이름 자동 완성

`[`를 입력하면 자동 완성 팝업이 열려 **알려진 모든 Inno Setup 섹션 이름**을 제공합니다. 템플릿은 파일 형식이나 버전 필터링이 없는 자유 텍스트이므로 항상 전체 섹션 집합이 제안됩니다(`.iss`/`.isl`의 컨텍스트 제한 목록과 다름). 제안을 수락하면 닫는 `]`가 자동으로 삽입됩니다.

### 괄호 매칭

`[ ]`(구조적 섹션 괄호)와 `( )`에 대해 매칭이 제공되므로, 템플릿 조각 내 탐색과 균형 맞추기가 스크립트와 동일하게 작동합니다.

### 포함 경로 자동 완성 및 탐색

`#include "…"` 지시문 내에서 `.ist` 템플릿이 다른 포함 가능한 파일과 함께 자동 완성으로 제공되며, 경로는 템플릿 파일로 해석되어 **정의로 이동** 탐색이 가능합니다.

## 템플릿이 의도적으로 **갖지 않는** 기능

`.ist` 파일은 의도적으로 비구조화된 조각이므로, 몇 가지 스크립트 전용 기능이 꺼져 있습니다:

- **검증/주석기 없음** — 손상되었거나 컨텍스트를 벗어난 Inno Setup 내용이 ERROR 또는 WARNING 강조를 생성하지 않습니다.
- **구조 뷰 없음** — 템플릿에는 표시할 보장된 섹션 트리가 없습니다.

이러한 기능은 호스트 `.iss`/`.isl` 스크립트에서는 계속 사용할 수 있으며, 거기서 템플릿의 내용이 실제의 포함 해석된 컨텍스트에서 분석됩니다.

---

## 템플릿 만들기

IDE의 *새 파일* 메뉴에서 **새로 만들기 → Inno Setup 템플릿**을 사용합니다. 템플릿은 자유 텍스트이므로 대화 상자는 파일 이름만 묻고 빈 `.ist` 파일을 만듭니다 — 내용 골격은 생성되지 않습니다.
