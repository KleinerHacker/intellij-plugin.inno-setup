# Inno Setup スクリプトファイル

このプラグインは Inno Setup スクリプトファイル（`.iss`）をメインのインストーラー定義フォーマットとしてサポートします。スクリプトファイルはインストーラーが何をビルドするか、何をインストールするか、どの言語を提供するか、Setup と Uninstall でどのランタイムアクションを実行するかを記述します。

![Inno Setup スクリプトエディター](assets/images/iss.png)

---

## サポートされるセクション

`.iss` ファイルには以下を含めることができます：

- `[Setup]` — インストーラーメタデータ、出力設定、ウィザードの動作、権限、署名、圧縮、バージョン要件
- `[Types]`、`[Components]`、`[Tasks]` — 選択可能なインストールモード、機能グループ、オプションアクション
- `[Dirs]`、`[Files]`、`[Icons]`、`[Registry]`、`[INI]`、`[InstallDelete]`、`[UninstallDelete]` — ファイルシステム、ショートカット、レジストリ、INI、クリーンアップ操作
- `[Run]` と `[UninstallRun]` — インストールまたはアンインストール時に実行するコマンド
- `[Languages]`、`[LangOptions]`、`[Messages]`、`[CustomMessages]` — 多言語インストーラーとローカライズされたテキスト
- `[ISSigKeys]` — `.issig` 署名検証に使用する公開鍵
- `[Code]` — Pascal スクリプトカスタムロジック

`[Setup]` は中心的なスクリプトセクションで、通常のインストーラースクリプトには必須です。他のセクションはオプションで、インストーラーワークフローに応じて組み合わせることができます。

## 編集機能

### シンタックスハイライト

スクリプトのすべての要素が個別に色付けされます：

- **セクションヘッダー**（`[Setup]`、`[Files]` など）が構造マーカーとして際立つ
- **ディレクティブキー**と**パラメーターキー**が値とは別に強調表示される
- `{app}`、`{autopf}`、`{group}`、`{cm:…}` などの**組み込み定数**が値と文字列内で色付けされる
- ファイル先頭の **ISPP プリプロセッサー行**（`#define`、`#include`、`#if` など）が独自のカラースキームを持つ
- **コメント**（`;` で始まる行）が視覚的に控えめに表示される

### コード補完

入力に応じてコンテキスト対応の候補が提示されます：

- `[` の後のセクション名
- `[Setup]` のディレクティブキーと他のすべてのセクションのパラメーターキー
- 既知のフラグ値と列挙型オプション値
- `{#` の後および `#define`/`#include` キーワードの後の ISPP 変数名
- フラグアイコンとロケール名付きの `Languages:` パラメーターの言語識別子

### インラインドキュメント

ディレクティブキーまたはパラメーターキーにカーソルを当てると、バンドルされた Inno Setup 仕様から説明が表示されます（受け入れ可能な値と注意事項を含む）。エディターを離れる必要はありません。

### 参照解決

プラグインは宣言と使用箇所間のクロスリファレンスを解決します：

| 参照タイプ                 | 宣言                                                  | 使用箇所                                               |
|----------------------------|-------------------------------------------------------|--------------------------------------------------------|
| タスク / コンポーネント / タイプ | `[Tasks]` / `[Components]` / `[Types]` の `Name:` | `Tasks:`、`Components:`、`Types:` パラメーター         |
| ISPP 定義                  | `#define Name`                                        | 値と文字列内の `{#Name}`                               |
| 言語プレフィックス          | `[Languages]` の `Name:`                              | `[Messages]` の `german.MessageKey`                    |
| カスタムメッセージ          | `[CustomMessages]` の `Key=`                          | 値内の `{cm:Key}` 定数                                 |

サポートされるすべての参照タイプで定義へ移動（**Ctrl+B** / **Cmd+B**）と使用箇所の検索（**Alt+F7**）が機能します。リネームリファクタリングはすべての使用箇所を一貫して更新します。

### インレイヒント

`[Languages]` エントリーの `MessagesFile:` 値の横に言語フラグアイコンがインラインで表示されます。ヒントにはロケール名（例：*English (United States)*）が表示され、`.isl` ファイルを開かずに参照されている言語を即座に確認できます。

### バリデーションとクイックフィックス

アノテーターがエディターに問題を直接ハイライト表示します：

- 不明またはスペルミスのディレクティブ/パラメーターキー
- 不足している必須パラメーター（追加するクイックフィックス付き）
- 冗長なフラグ（削除するクイックフィックス付き）
- 最後のパラメーターの末尾セミコロン（削除するクイックフィックス付き）
- `[Code]` が最後のセクションでない（移動するクイックフィックス付き）
- 空のセクション（削除するクイックフィックス付き）
- 不足している必須セクション（追加するクイックフィックス付き）
- 未解決の定数と参照

### 構造ビュー

構造ツールウィンドウ（**Alt+7**）はすべてのセクションとエントリーのツリービューを表示します。エントリーをクリックすると対応する行にジャンプします。

### コードの折りたたみ

セクションと長いパラメーターエントリーは個別に折りたたむことができ、大きなスクリプトを操作する際の視覚的なノイズを軽減します。

### 括弧と引用符のマッチング

エディターは `{`、`[`、`"` を自動的に閉じ、カーソルが隣にあるときにマッチするペアをハイライト表示します。

### コードエントリーの移動

セクション内のパラメーターエントリーは **Alt+Shift+上/下** で手動でカットアンドペーストせずに上下に移動できます。

## プリプロセッサー（ISPP）

ISPP プリプロセッサーディレクティブはスクリプトファイルに注入され、`#define` 名に対して独自のハイライト、補完、リネーム、使用箇所の検索サポートを受けます。セクション値内のインライン `{#Name}` 参照は `#define` 宣言に解決され、同じリネーム/使用箇所検索フローに参加します。

サポートされるディレクティブ、標準の定義済み変数、インライン `{#…}` 出力については、[Inno Setup プリプロセッサー](preprocessor/overview.md)を参照してください。
