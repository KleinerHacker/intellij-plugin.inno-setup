# `#include` / `#file`

`#include` はコンパイル時に別のファイルの内容をスクリプトに貼り付け、`#file` はファイルを読み込んでその内容
をプリプロセッサーが使えるようにします。どちらも外部の内容をスクリプトに取り込みます。

---

## 構文

```ini
#include "filename.iss"
#include <filename.iss>
#file "data.txt"
```

- `#include "file"` は読み込み元スクリプトからの相対で解決されます（絶対パスはそのまま使用）。山かっこ形式は
  設定されたインクルードパスを検索します。
- `#file "file"` はファイルを読み込み、他のディレクティブが参照できる一時ファイル名を返します。

---

## `#include` の操作

プラグインは `#include` を第一級の参照として扱います：

- **ファイルへ移動** — **Ctrl+B** / **Cmd+B** で参照先ファイルへジャンプ。入力中にパスが補完されます。
- **パスの自動更新** — IDE で対象ファイルをリネーム・移動すると `#include` のパスが更新されます。
- **`#include` の内容をインライン化** — `#include` 行での **Alt+Enter** インテンションが、その行をファイルの
  内容（1 階層のみ）で置き換えます。その後、インライン化したファイルを削除するか尋ねられます。
- **選択範囲を `#include` ファイルに抽出** — 行を選択して現在のスクリプトの隣の新しいファイルに移動し、
  選択範囲はその新しいファイルの `#include` に置き換えられます。
- **有効なスクリプトを表示** — インクルードを完全に解決したスクリプトを読み取り専用タブで開きます。

```ini
#include "common\\settings.iss"

[Setup]
AppName={#MyAppName}      ; インクルードファイル内で定義
```

---

## 検証

`#include` 行自体がチェックされます。存在しないファイル、リテラルでない、または空のパスはエラーとして
報告されます。インクルードファイル**内部**で検出された問題（未知のディレクティブ、フラグ、未定義の定数）は
読み込み元スクリプトの `#include` 行に表示され、必須セクションのチェックもインクルードが寄与する内容を
考慮します。
