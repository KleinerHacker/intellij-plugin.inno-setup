# `#pragma`

`#pragma` はプリプロセッサー自体を制御します。出力を生成する代わりに、**サブコマンド**を受け取り、
プリプロセッサーがスクリプトをどのように読み取り、解析し、報告するかを調整します。プラグインは付属の
仕様からすべてのサブコマンドを把握し、その後に続く引数を検証します。

---

## 構文

```ini
#pragma <sub-command> [arguments]
```

`#pragma` の後の最初の単語がサブコマンドで、その後はすべて引数です。未知のサブコマンドはエラーとして
報告され、欠落した引数や型の合わない引数も同様です。

---

## サブコマンド

| サブコマンド         | 引数       | 目的                               |
|----------------|----------|----------------------------------|
| `option`       | オプションフラグ | プリプロセッサーの一般的な読み取り/出力オプション        |
| `parseroption` | オプションフラグ | 式の解析を制御するオプション                   |
| `message`      | 文字列      | コンパイラウィンドウに情報メッセージを表示            |
| `warning`      | 文字列      | コンパイラウィンドウに警告を表示                 |
| `error`        | 文字列      | ダイアログボックスにエラーメッセージを表示            |
| `verboselevel` | 整数（0–10） | メッセージの詳細度しきい値を設定                 |
| `inlinestart`  | 文字列      | インラインディレクティブの開始区切り文字を設定（既定 `{#`） |
| `inlineend`    | 文字列      | インラインディレクティブの終了区切り文字を設定（既定 `}`）  |
| `include`      | 文字列      | インクルードファイルのセミコロン区切り検索パスを設定       |
| `spansymbol`   | 文字列      | 行継続文字を設定（先頭の 1 文字のみ）             |

---

## オプションフラグ: `option` と `parseroption`

`option` と `parseroption` は `-<letter>(+|-)` 形式のフラグを 1 つ以上、空白で区切って受け取ります。
`+` はオプションをオン、`-` はオフにします。プラグインは未知の文字や不正な形式のフラグ（ダッシュや符号の
欠落）をエラーとして報告します。

### `option` フラグ

| フラグ | 既定 | 意味       |
|-----|----|----------|
| `c` | オン | コンパイラへ出力 |
| `e` | オン | 空行を出力    |
| `v` | オフ | 詳細モード    |

### `parseroption` フラグ

| フラグ | 既定 | 意味                |
|-----|----|-------------------|
| `b` | オン | ブール演算の短絡評価        |
| `m` | オフ | 乗算の短絡評価           |
| `p` | オン | Pascal 形式の文字列リテラル |
| `u` | オフ | 未宣言の識別子を許可        |

```ini
#pragma option -v+            ; 詳細出力を有効化
#pragma parseroption -b- -u+  ; ブール短絡を無効化し、未宣言の識別子を許可
```

---

## 式サブコマンド

`message`、`warning`、`error`、`include`、`inlinestart`、`inlineend`、`spansymbol` は**文字列式**を、
`verboselevel` は**整数式**を受け取ります。プラグインは `#define` と同じエンジンで引数を解析し型チェック
するため、誤った型（文字列が必要な場所に数値など）はエラーとなり、`verboselevel` は 0–10 の範囲でなければ
なりません。

```ini
#define BuildId 42
#pragma message "Building configuration #" + Str(BuildId)
#pragma verboselevel 9
#pragma inlinestart "$("
#pragma inlineend ")"
```

これらの式内の識別子は、`#define` の値内と同様にあなたの `#define` を参照します。解決され、定義への移動、
使用箇所検索、リネームをサポートし、未知の名前は未解決の参照としてエラーになります。

---

## エディタサポート

- サブコマンド名、オプションフラグの文字と形式、引数の型の**検証**
- `#pragma ` の後のサブコマンドの**補完**、および `#pragma option `/`#pragma parseroption ` の後の
  オプションフラグの補完
- 式引数内で使用される `#define` の**参照解決、使用箇所検索、リネーム**
