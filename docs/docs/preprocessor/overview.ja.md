# Inno Setup プリプロセッサー（ISPP）

Inno Setup プリプロセッサー（ISPP）はスクリプトのコンパイル**前**に実行され、ディレクティブ、マクロ、式を使ってスクリプトを生成・変更できます。プラグインはプリプロセッサー行を独自の言語として注入するため、専用のハイライト、補完、検証、リネーム、使用箇所検索のサポートを受けます。本セクションは公式の
[Inno Setup プリプロセッサードキュメント](https://jrsoftware.org/ishelp/topic_isppoverview.htm)の構成に従います。

---

## プリプロセッサーディレクティブとは？

ディレクティブは `#` で始まる行です。コンパイル時に評価され、最終的なインストーラーには現れません。プラグインはバンドルされた ISPP 仕様に対してキーワードを検証します。未知のディレクティブ（仕様に定義されていないもの）はエラーとしてフラグ付けされます（大文字小文字を区別しません）。未知のセクション/フラグ/定数チェックと同様です。

---

## サポートされるディレクティブ

| グループ | ディレクティブ |
|----------|----------------|
| 定義 | `#define`、`#undef`、`#dim`、`#redim` |
| インクルード | `#include`、`#file` |
| 出力 | `#emit`、`#expr`、`#insert`、`#append` |
| 条件 | `#if`、`#elif`、`#else`、`#endif`、`#ifdef`、`#ifndef`、`#ifexist`、`#ifnexist` |
| ループとマクロ | `#for`、`#sub`、`#endsub` |
| その他 | `#pragma`、`#error` |

すべてのディレクティブキーワードはハイライト、補完（`#` の後）され、仕様に対して検証されます。プラグインが完全なセマンティクス（参照解決、リネーム、使用箇所検索）でサポートするディレクティブには専用ページがあります：

- [`#define`](define.md) — マクロの宣言と使用、および標準の定義済み変数

---

## インライン出力 `{#…}`

通常のスクリプト行内では、`{#expr}` は `{#emit expr}` のインライン形式です。プリプロセッサーは式を評価し、プレースホルダーをその値で置き換えます。式は通常マクロまたは定義済み変数です。詳細とこの方法で使用できる定義済み変数については、[`#define`](define.md) を参照してください。

---

## `#include` の操作

`#include "file"` のパスは参照先の `.iss` ファイルに解決されます（インクルードするスクリプトの
ディレクトリからの相対パス。絶対パスはそのまま使用されます）。**Ctrl+B** / **Cmd+B** でファイルへ
ジャンプでき、入力中にパスが補完されます。インクルードの操作を容易にする 2 つのエディターアクション
があります。

- **`#include` の内容をインライン展開** — 既存ファイルに解決される `#include` 行にキャレットを置くと、
  インテンション（**Alt+Enter**）がその行をファイルの内容そのままで置き換えます。展開は 1 階層のみで、
  挿入されたテキスト内のネストした `#include` 行はそのまま保持されます。その後、インライン展開した
  インクルードファイルを削除するか確認されます（既定：いいえ）。
- **選択範囲を `#include` ファイルに抽出** — 1 行以上を選択してインテンションを実行すると、現在の
  スクリプトの隣に新しいファイルとして切り出します。ファイル名を尋ね（既存ファイルを上書きする前にも
  確認します）、選択された行全体をその新しいファイルの `#include` に置き換えます。

参照先ファイルを IDE で**リネームまたは移動**すると、`#include` のパスは自動的に更新され、ファイルを
指し続けます。

### 検証

`#include` 行自体もチェックされます。存在しないファイルや見つからないファイル、リテラルでないパスや空の
パスはエラーとしてフラグ付けされます。インクルードされたファイル**内部**で検出された問題（未知の
ディレクティブ、フラグ、未定義の定数、警告）は、インクルードするスクリプトの `#include` 行に表示され、
必須セクションのチェックもインクルードが提供する内容を正しく考慮します。

### 有効なスクリプトを表示

**有効なスクリプトを表示（Show Effective Script）**アクションは、`#include` を完全に解決した（すべての
インクルードをインライン展開した）スクリプトを読み取り専用タブで開き、コンパイラーが実際に見る内容を
確認できます。

---

## エディターサポート

- ディレクティブ、マクロ名、インライン `{#…}` 参照の**構文ハイライト**
- ディレクティブキーワード、`#define` と値を持つ定義済み変数、組み込み関数の**補完**
- 未知のディレクティブ、未知の `{#…}` 参照、未使用の `#define`、壊れたまたは問題のある `#include` 行の**検証**
- `#define` とそのすべての `{#Name}` 使用箇所にわたる**リネーム**と**使用箇所検索**
- `#include` の**インライン**と**抽出**インテンション、リネーム/移動時のパス自動更新
- **有効なスクリプトを表示** — `#include` を完全に解決したスクリプトを読み取り専用タブで表示
