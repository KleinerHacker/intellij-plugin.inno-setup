# Inno Setup 전처리기(ISPP)

Inno Setup 전처리기(ISPP)는 스크립트가 컴파일되기 **전에** 실행되며, 지시문, 매크로, 표현식을 사용하여 스크립트를 생성하거나 변경할 수 있습니다. 플러그인은 전처리기 줄을 자체 언어로 주입하므로 전용 강조 표시, 완성, 검증, 이름 바꾸기, 사용 찾기 지원을 받습니다. 이 섹션은 공식
[Inno Setup 전처리기 문서](https://jrsoftware.org/ishelp/topic_isppoverview.htm)의 구조를 따릅니다.

---

## 전처리기 지시문이란?

지시문은 `#`로 시작하는 줄입니다. 컴파일 시점에 평가되며 최종 설치 프로그램에는 나타나지 않습니다. 플러그인은 번들된 ISPP 사양에 대해 키워드를 검증합니다. 알 수 없는 지시문(사양에 정의되지 않은 것)은 오류로 표시됩니다(대소문자 구분 안 함). 알 수 없는 섹션/플래그/상수 검사와 동일합니다.

---

## 지원되는 지시문

| 그룹 | 지시문 |
|------|--------|
| 정의 | `#define`, `#undef`, `#dim`, `#redim` |
| 포함 | `#include`, `#file` |
| 출력 | `#emit`, `#expr`, `#insert`, `#append` |
| 조건 | `#if`, `#elif`, `#else`, `#endif`, `#ifdef`, `#ifndef`, `#ifexist`, `#ifnexist` |
| 루프 및 매크로 | `#for`, `#sub`, `#endsub` |
| 기타 | `#pragma`, `#error` |

모든 지시문 키워드는 강조 표시되고 완성되며(`#` 뒤) 사양에 대해 검증됩니다. 플러그인이 완전한 의미 체계(참조 해석, 이름 바꾸기, 사용 찾기)로 지원하는 지시문은 전용 페이지가 있습니다:

- [`#define`](define.md) — 매크로 선언 및 사용, 그리고 표준 사전 정의 변수

---

## 인라인 출력 `{#…}`

일반 스크립트 줄 안에서 `{#expr}`는 `{#emit expr}`의 인라인 형식입니다. 전처리기는 표현식을 평가하고 자리 표시자를 해당 값으로 바꿉니다. 표현식은 일반적으로 매크로 또는 사전 정의 변수입니다. 자세한 내용과 이 방식으로 사용할 수 있는 사전 정의 변수는 [`#define`](define.md)을 참조하세요.

---

## `#include` 작업

`#include "file"` 경로는 참조된 `.iss` 파일로 해석됩니다(포함하는 스크립트의 디렉터리 기준 상대 경로,
절대 경로는 그대로 사용). **Ctrl+B** / **Cmd+B** 로 파일로 이동할 수 있으며 입력 중에 경로가 완성됩니다.
include 작업을 더 쉽게 해 주는 두 가지 편집기 동작이 있습니다.

- **`#include` 내용 인라인 삽입** — 기존 파일로 해석되는 `#include` 줄에 캐럿을 두면 인텐션
  (**Alt+Enter**)이 해당 줄을 그 파일의 내용 그대로 바꿉니다. 한 단계만 펼치며, 삽입된 텍스트 안의
  중첩된 `#include` 줄은 그대로 유지됩니다. 이후 인라인으로 삽입한 포함 파일을 삭제할지 묻습니다
  (기본값: 아니요).
- **선택 영역을 `#include` 파일로 추출** — 한 줄 이상을 선택하고 인텐션을 실행하면 현재 스크립트 옆에
  새 파일로 분리합니다. 파일 이름을 묻고(기존 파일을 덮어쓰기 전에도 확인) 선택한 전체 줄을 새 파일의
  `#include`로 바꿉니다.

참조된 파일을 IDE에서 **이름 바꾸기 또는 이동**하면 `#include` 경로가 자동으로 갱신되어 파일을 계속
가리킵니다.

---

## 편집기 지원

- 지시문, 매크로 이름, 인라인 `{#…}` 참조에 대한 **구문 강조 표시**
- 지시문 키워드, `#define` 및 값을 가진 사전 정의 변수, 내장 함수의 **완성**
- 알 수 없는 지시문, 알 수 없는 `{#…}` 참조, 사용되지 않는 `#define`의 **검증**
- `#define` 및 모든 `{#Name}` 사용에 걸친 **이름 바꾸기**와 **사용 찾기**
- `#include`의 **인라인** 및 **추출** 인텐션, 이름 바꾸기/이동 시 경로 자동 갱신
