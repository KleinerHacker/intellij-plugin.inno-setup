# Inno Setup 预处理器（ISPP）

Inno Setup 预处理器（ISPP）在脚本编译**之前**运行，允许你通过指令、宏和表达式生成或修改脚本。插件将预处理器行作为独立语言注入，因此它们获得专门的高亮、补全、验证、重命名和查找用法支持。本节遵循官方
[Inno Setup 预处理器文档](https://jrsoftware.org/ishelp/topic_isppoverview.htm)的结构。

---

## 什么是预处理器指令？

指令是以 `#` 开头的行。它在编译时求值，且不会出现在最终安装程序中。插件会根据其捆绑的 ISPP 规范验证关键字——未知指令（规范中未定义的）会被标记为错误（不区分大小写），与未知节/标志/常量检查一致。

---

## 支持的指令

| 分组 | 指令 |
|------|------|
| 定义 | `#define`、`#undef`、`#dim`、`#redim` |
| 包含 | `#include`、`#file` |
| 输出 | `#emit`、`#expr`、`#insert`、`#append` |
| 条件 | `#if`、`#elif`、`#else`、`#endif`、`#ifdef`、`#ifndef`、`#ifexist`、`#ifnexist` |
| 循环与宏 | `#for`、`#sub`、`#endsub` |
| 其他 | `#pragma`、`#error` |

所有指令关键字都会被高亮、补全（`#` 之后）并根据规范验证。插件还为某些指令提供完整语义支持（引用解析、重命名、查找用法），它们有各自的页面：

- [`#define`](define.md) — 声明和使用宏，以及标准预定义变量

---

## 内联输出 `{#…}`

在普通脚本行内，`{#expr}` 是 `{#emit expr}` 的内联形式：预处理器计算表达式并用其值替换占位符。表达式通常是宏或预定义变量。详情及可通过此方式使用的预定义变量，请参阅 [`#define`](define.md)。

---

## 编辑器支持

- 对指令、宏名称和内联 `{#…}` 引用的**语法高亮**
- 指令关键字、`#define` 与带值预定义变量以及内置函数的**补全**
- 对未知指令、未知 `{#…}` 引用以及从未使用的 `#define` 的**验证**
- 跨 `#define` 及其所有 `{#Name}` 用法的**重命名**和**查找用法**
