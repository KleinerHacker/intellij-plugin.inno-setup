# ビルド設定

**ビルド**サブページは IDE 設定の**ビルド、実行、デプロイ → Inno Setup → ビルド**にあります。

![Inno Setup ビルド設定](assets/images/settings_build.png)

これらの設定は**プロジェクトスコープ**です（グローバルではなくプロジェクトごとに保存）。

---

## ビルド

| オプション                           | 説明                                                                          |
|---------------------------------|-----------------------------------------------------------------------------|
| **プロジェクトビルド時に .iss ファイルをコンパイル** | 有効にすると、プロジェクトがビルドされるたびに、プロジェクト内のすべてのトップレベル `.iss` スクリプトが `ISCC` でコンパイルされます。 |
| **出力**                          | コンパイルされたインストーラー出力の場所を制御します。以下の値を参照してください。                                   |

**出力値**

| 値                             | 説明                                                                 |
|-------------------------------|--------------------------------------------------------------------|
| **スクリプトで定義されたとおり**            | スクリプトの `[Setup] OutputDir` をそのままにします——`/O` スイッチを `ISCC` に渡しません。    |
| **プロジェクトビルドディレクトリへ**（*デフォルト*） | 相対 `OutputDir` をプロジェクトのビルドフォルダー（`out`/`target`/`build`）にリダイレクトします。 |
| **ドライビルド——検証のみ、出力なし**         | ネイティブの `ISCC` `/O-` スイッチを渡してスクリプトを検証しますが、セットアップファイルは生成しません。        |

---

## ビルド構成

**ビルド構成**は C/C++ のビルド構成に相当する Inno Setup の仕組みで、[実行構成](run-configuration.md)が名前で参照する、
名前付きのコンパイルオプション一式です。オプションは一箇所にまとまっているため、複数の実行で共有でき、
編集すると参照しているすべての実行に一度に反映されます。

| オプション            | 説明                                                                          |
|------------------|-----------------------------------------------------------------------------|
| **プリプロセッサシンボル**  | `/D` としてコンパイラに渡されるシンボル（例: `DEBUG`、`VERSION=2`）。複数指定する場合はカンマ・セミコロン・空白で区切ります。 |
| **出力ディレクトリ**     | インストーラーの書き出し先を上書きします。相対パスはプロジェクトのビルドフォルダー配下に解決されます。空欄のままにすると上記の**出力**の規則が適用されます。 |
| **追加の ISCC オプション** | その他の生の `ISCC` コマンドラインオプションを空白区切りで指定します。空白を含む値は二重引用符で囲みます。                   |

一覧の管理には**追加**、**コピー**、**名前を変更**、**削除**を使用します。構成は少なくとも 1 つ残す必要があります。

### デフォルト

ビルド構成をまだ持たないプロジェクトは、2 つの構成から始まります。

| 名前          | シンボル     | 用途                    |
|-------------|----------|-----------------------|
| **Release** | *(なし)*   | 何も定義しない素のビルド。         |
| **Debug**   | `DEBUG`  | 新しい実行構成のデフォルト。        |

### 保存場所

各構成は**プロジェクトの `.build` ディレクトリ内の 1 ファイル**として `.idea` と並んで保存されます——
プラットフォームが共有可能な実行構成を `.run` に置くのと同じレイアウトです。構成ごとに 1 ファイルなのでレビューとマージがしやすく、
バージョン管理を通じてチームと共有できます。

### ビルドへの影響

選択されたビルド構成の内容は、ビルドの最新性チェックの一部です。そのため実行を `Debug` から `Release` に切り替えたり、
単に `Debug` のシンボルを編集したりすると、以前に生成されたインストーラーは無効となり再ビルドされます。
構成の名前変更では再ビルドされません——名前はコンパイル内容の一部ではないためです。
