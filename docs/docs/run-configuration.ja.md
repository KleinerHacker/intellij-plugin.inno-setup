# 実行構成

このプラグインは専用の **Inno Setup** 実行構成タイプを提供し、IDE 内で `.iss` スクリプトをコンパイルして生成されたインストーラーをすぐに起動できます。

---

## 実行構成の作成

プロジェクトビューで **`.iss` ファイルを右クリック**し、**実行**または**デバッグ**を選択すると、実行構成が自動的に作成されます。
**実行 → 構成の編集…** から手動で作成することもできます。**+** をクリックして **Inno Setup** を選択してください。

![Inno Setup 実行構成](assets/images/run.png)

---

## 構成オプション

| オプション      | 説明                                                                                        |
|------------|-------------------------------------------------------------------------------------------|
| **スクリプト**  | コンパイルするトップレベルの `.iss` スクリプトへのパス。ドロップダウンにはプロジェクト内のすべてのトップレベルスクリプトが表示されます。パスを直接入力することもできます。 |
| **言語**     | 起動時にインストーラーの言語を選択します。スクリプトの `[Languages]` セクションに 2 つ以上のエントリーがある場合にのみ表示されます。               |
| **デバッグ出力** | 有効にすると、インストーラーに `/DBGMSG` が渡され、インストール中に診断メッセージがコンソールに出力されます。                              |
| **ビルド構成** | この実行がコンパイルに使用する、名前付きのコンパイルオプション一式——プリプロセッサシンボル、出力ディレクトリの上書き、追加の `ISCC` オプション。実行構成に保存されるのは*名前*だけで、オプション自体は[ビルド設定](settings-build.md)にあります。そのため編集すると、その構成を参照するすべての実行に反映されます。新しい実行構成は **Debug** から始まります。 |

---

## ビルド構成を指定した実行

ビルド構成は実行時に指定が必要な唯一の項目であるため、どの入口からも選択できます。

- `[Setup]` セクション横の**ガターアイコン**をクリックすると、すべてのビルド構成の一覧が開きます。選んだ構成でスクリプトが実行されます。
- `.iss` ファイルの**コンテキストメニュー**（プロジェクトビューまたはエディタ）では、**スクリプトを実行**と**スクリプトをビルド**がサブメニューとして表示され、それぞれにビルド構成が並びます。
- 保存済みの実行構成は、その**ビルド構成**ドロップダウンで選ばれたものを使用します。

参照先のビルド構成が削除されている場合、実行は他の構成に黙って切り替えるのではなくエラーを報告します。

---

## エディタでのプリプロセッサシンボル

エディタは**選択中**の実行構成が参照するビルド構成のシンボルで `#ifdef` の分岐を判定します。そのため、スクリプト上で淡色表示される内容は次の実行がビルドする内容と一致します。
ツールバーで選択中の構成を切り替えると、条件は直ちに再評価されます。

Inno Setup の実行構成が選択されていない場合は、スクリプトの上にその旨のバナーが表示されます——シンボルを供給できないため、条件は未確定のままです。
バナーには既存の Inno Setup 実行構成のドロップダウンが組み込まれており、その場で選択できます。

---

## 動作の仕組み

1. スクリプトは ISCC でコンパイルされます（[ビルド統合](build.md)と同じパイプライン）。その際、選択されたビルド構成の `/D` シンボルと追加オプションが渡されます。
2. プロジェクトの出力モードが**ドライビルド**に設定されている場合、プラグインは自動的に出力を一時ディレクトリにリダイレクトし、実際のインストーラーを生成して起動できるようにします。
3. 生成された `setup.exe` が実行され、そのプロセス出力が**実行**ツールウィンドウにストリーミングされます。

ビルドが再利用されるのは、関与するファイル、出力先、**および**ビルド構成の内容が前回の成功したビルドから変わっていない場合だけです。
