# コードスタイル

プラグインは **コードの整形**（<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>L</kbd>）で `.iss` / `.isl` スクリプトを整形します。
ルールは **設定 ▸ エディター ▸ コードスタイル ▸ Inno Setup** にあり、既定ではすべて有効です。

---

## ルール

| ルール                          | 効果                                                    | 例                                          |
|-------------------------------|-------------------------------------------------------|-------------------------------------------|
| **セクション間はちょうど 1 行の空行** | 2 つの `[Section]` ブロック間の空きを空行 1 行に統一（または挿入）します。 | `…value`⏎⏎⏎`[Files]` → `…value`⏎⏎`[Files]` |
| **セクションの角括弧内にスペースを入れない** | セクション名の角括弧を詰めます。                             | `[ Setup ]` → `[Setup]`                   |
| **ディレクティブの `=` の前後にスペース** | `Key = Value` ディレクティブの `=` の両側に 1 つずつスペースを入れます。 | `AppName=My App` → `AppName = My App`     |
| **パラメータの `:` の後にスペース** | `Key: Value` パラメータの `:` の前は空けず、後に 1 つスペースを入れます。 | `DestDir:"{app}"` → `DestDir: "{app}"`    |
| **パラメータ間の `;` の後にスペース** | パラメータ対を区切る `;` の前は空けず、後に 1 つスペースを入れます。       | `"a" ;DestDir` → `"a"; DestDir`           |
| **キーの前に先頭スペースを入れない** | キー / パラメータ / セクション見出しの行を 0 桁目から始めます。         | `····AppName = A` → `AppName = A`         |
| **算術演算子の前後にスペース**   | プリプロセッサ式の `+ - * / %`（二項演算子のみ）の両側にスペースを入れます。 | `#define X 2+3*4` → `#define X 2 + 3 * 4`  |

各ルールは設定ページで個別に無効化できます。`=`・`:`・`;`・角括弧・先頭スペースのオプションは **スペース (Spacing)**、
空行のオプションは **空行 (Blank Lines)** にあります。

---

## 変更されない箇所

- **`[Code]`** セクション（Pascal Script）とそれ以降のすべて — インデントとレイアウトは保持されます。
- 値そのもの — 区切り文字の**周囲**の空白のみを整え、値のテキストは変更しません。
- **単項**符号（`-3`）、識別子やバージョン文字列内の `-`、および引用符付き文字列の内容は算術演算子として扱いません。
