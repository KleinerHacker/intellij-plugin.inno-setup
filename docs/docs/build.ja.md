# ビルド統合

このプラグインは Inno Setup のコマンドラインコンパイラー **ISCC** を IDE に直接統合し、エディターを離れずに `.iss`
スクリプトをコンパイルできます。ビルド機能を使用する前に、**ビルド、実行、デプロイ → Inno Setup → 一般**で Inno Setup
のインストールディレクトリが設定されていることを確認してください（[設定](settings.md)参照）。

---

## ビルドのトリガー

### コンテキストメニューアクション

プロジェクトビューまたはエディタータブで任意の `.iss` ファイルを右クリックし、**Build Inno Setup Script** を選択します。このアクションは
`.iss` ファイルに対してのみ表示され、別のスクリプトから `#include`
されているスクリプトに対しては無効になります（説明付きのツールチップ付き）——それらはトップレベルの親から構築する必要があります。

### プロジェクトビルド時の自動ビルド

[ビルド設定](settings-build.md)で**プロジェクトビルド時に .iss ファイルをコンパイル**が有効になっている場合、IDE
がプロジェクトをビルドするたびに（例：**ビルド → プロジェクトのビルド**またはハンマーアイコン経由）、プロジェクト内のすべてのトップレベル
`.iss` スクリプトが自動的にコンパイルされます。他のスクリプトにインクルードされているスクリプトは自動的にスキップされます。

## ビルド出力コンソール

![Inno Setup ビルド出力](assets/images/build.png)

ビルド結果は**ビルド**ツールウィンドウの専用 **Inno Setup** ノードに表示されます。コンパイルされた各スクリプトには、その名前とエラーまたは警告の数を示す独自の子ノードがあります。

### コンソール出力

右側のパネルには生の ISCC 出力が行ごとに表示されます——進捗メッセージ、セクション解析ノート、コンパイラー診断：

| 行タイプ    | 外観        | 例                                                                  |
|---------|-----------|--------------------------------------------------------------------|
| **進捗**  | 普通の白色テキスト | `Parsing [Files] section, line 22`                                 |
| **エラー** | 赤色テキスト    | `Error on line 22 in C:\...\demo.iss: Source file "..." not found` |
| **警告**  | 黄色テキスト    | `Warning on line 5 in C:\...\demo.iss: ...`                        |

### 構造化されたセクション出力とフォールディング

ISCC の出力は、1 本の長いフラットなログではなく構造化された形式で表示されます：

- **セクションノード** — 同じ Inno Setup セクションに属する連続した出力行
  （`Parsing [Setup] section …`、`Parsing [Languages] section …` など）は、ビルドツリー内の 1 つのノードに
  まとめられ、セクション名と折りたたまれた行数でラベル付けされます（例：**`[Setup] (8)`**）。
  セクションノードはビルドの全体ステータスに関係なく**常に**表示され、内容に応じて
  **INFO**、**WARN**、**ERROR** のいずれかの重大度を持ちます。
- **コンソールフォールド** — コンソール内では、インデントされた詳細行（`[Languages]` の下の
  `Reading file: …` / `Messages in script file` など）がデフォルトで折りたたまれ、プレースホルダーに
  隠れた行数が表示されます。フォールドを展開すると個々の行を確認できます。

これにより出力がコンパクトに保たれ、セクションごとに 1 エントリーをひと目で把握でき、必要な箇所だけ
詳細を展開できます。

### ナビゲーション可能なエラーリンク

ファイル位置を含むエラーと警告行にはクリック可能な **`line XX`** ハイパーリンクがあります。クリックすると参照された
`.iss` ファイルが開き、報告された行と列に直接カーソルが移動するため、スクリプトを手動で検索せずに問題を修正できます。

### ビルドツリー

ビルドツールウィンドウ左側のツリーに結果がまとめて表示されます：

- スクリプトノードの**赤いエラーアイコン**は少なくとも 1 つのコンパイラーエラーがあることを示します。
- **黄色の警告アイコン**は警告があるがエラーはないことを示します。
- 個々の問題エントリーが子ノードとして一覧表示され、クリックするとソースの位置にナビゲートします。

## 出力モード

コンパイルされたインストーラーの出力場所は[ビルド設定](settings-build.md)でプロジェクトごとに制御できます：

| モード                           | ISCC フラグ | 説明                                                             |
|-------------------------------|----------|----------------------------------------------------------------|
| **スクリプトで定義されたとおり**（*script*）  | *（なし）*   | `[Setup]` の `OutputDir` をそのまま使用                                |
| **プロジェクトビルドディレクトリへ**（*デフォルト*） | `/O`     | 相対 `OutputDir` をプロジェクトのビルドフォルダー（`out`/`target`/`build`）にリダイレクト |
| **ドライビルド — 検証のみ、出力なし**        | `/O-`    | セットアップファイルを生成せずにスクリプトを検証。CI チェックに便利                            |
