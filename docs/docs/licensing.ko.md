## Inno Setup

```
Copyright (C) 1997-2026 Jordan Russell. All rights reserved.
Portions Copyright (C) 2000-2026 Martijn Laan.
```

Inno Setup은 [jrsoftware.org](https://jrsoftware.org/isinfo.php)가 자체 허용적 라이선스로 공개한 무료 설치 관리자
빌더입니다. 전체 라이선스 본문은
[Inno Setup 저장소](https://github.com/jrsoftware/issrc/blob/main/license.txt)에서 확인할 수 있습니다.

**Inno Setup의 어떤 부분도 이 플러그인과 함께 배포되지 않습니다.** Inno Setup 컴파일러(`ISCC.exe`)는 별도로 설치해야 하며,
플러그인 설정에서 지정한 설치 디렉터리에서 호출됩니다.

### 파생 문서

코드 완성, 인라인 문서, 검증에 사용되는 섹션, 지시문, 매개변수, 상수, 언어 코드, 전처리기 설명은 공식
[Inno Setup 문서](https://jrsoftware.org/ishelp/)에서 파생된 것이며 Jordan Russell과 Martijn Laan이 보유한 저작권의 적용을
받습니다.

### 예제 스크립트

통합 테스트 스위트는 공식 Inno Setup 예제 스크립트로 플러그인을 검증합니다. 이 스크립트들은 이 저장소의 일부가 **아니며**,
테스트 실행 전에 고정된 `jrsoftware/issrc` 태그에서 빌드 디렉터리로 다운로드되고 실행 후 다시 삭제됩니다.
