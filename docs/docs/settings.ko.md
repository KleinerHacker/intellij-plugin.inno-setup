# 설정

이 플러그인은 IDE 설정(Windows/Linux에서는 **파일 → 설정**, macOS에서는 **IntelliJ IDEA → 설정**)의 **빌드, 실행, 배포** 아래에 **Inno Setup** 노드를 추가합니다.

---

## Inno Setup 설치

![Inno Setup 설정](assets/images/settings.png)

| 옵션                     | 설명                                                                             |
|--------------------------|----------------------------------------------------------------------------------|
| **설치 디렉토리**        | Inno Setup 설치 폴더의 경로. `ISCC.exe`와 `Compil32.exe`가 포함되어야 합니다.   |
| **감지된 버전**          | 선택된 디렉토리에서 찾은 Inno Setup 버전을 표시하는 읽기 전용 필드.             |

### 버전 유효성 검사

| 옵션                           | 설명                                                                                                                     |
|--------------------------------|--------------------------------------------------------------------------------------------------------------------------|
| **최소 Inno Setup 버전**       | 사용 가능한 버전 옵션을 감지된 메이저 버전으로 제한합니다. `.iss` 파일의 버전 인식 경고에 사용됩니다.                   |

이러한 설정은 **IDE 전체** 설정입니다(프로젝트별이 아닌 전역 IDE 구성에 저장됨).

---
