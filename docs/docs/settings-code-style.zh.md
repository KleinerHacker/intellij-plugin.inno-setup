# 代码样式

插件可通过 **重新格式化代码**（<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>L</kbd>）格式化 `.iss` / `.isl` 脚本。
相关规则位于 **设置 ▸ 编辑器 ▸ 代码样式 ▸ Inno Setup**，默认全部启用。

---

## 规则

| 规则                       | 效果                                                | 示例                                        |
|--------------------------|---------------------------------------------------|-------------------------------------------|
| **节之间恰好一个空行**    | 将两个 `[Section]` 块之间的间隔折叠（或插入）为一个空行。 | `…value`⏎⏎⏎`[Files]` → `…value`⏎⏎`[Files]` |
| **节方括号内不留空格**    | 收紧节名周围的方括号。                                | `[ Setup ]` → `[Setup]`                   |
| **指令中 `=` 两侧留空格** | `Key = Value` 指令中 `=` 两侧各留一个空格。            | `AppName=My App` → `AppName = My App`     |
| **参数中 `:` 后留空格**   | `Key: Value` 参数中 `:` 前不留空格、后留一个空格。      | `DestDir:"{app}"` → `DestDir: "{app}"`    |
| **参数间 `;` 后留空格**   | 分隔参数对的 `;` 前不留空格、后留一个空格。             | `"a" ;DestDir` → `"a"; DestDir`           |
| **键前不留前导空格**      | 键 / 参数 / 节标题行从第 0 列开始。                    | `····AppName = A` → `AppName = A`         |
| **算术运算符两侧留空格**  | 预处理器表达式中 `+ - * / %`（仅二元运算符）两侧各留一空格。 | `#define X 2+3*4` → `#define X 2 + 3 * 4`  |

每条规则均可在设置页单独关闭；`=`、`:`、`;`、方括号和前导空格选项位于 **空格（Spacing）** 下，空行选项位于
**空行（Blank Lines）** 下。

---

## 不受影响的内容

- **`[Code]`** 节（Pascal Script）及其之后的所有内容——其缩进与排版保持不变。
- 值本身——仅规范分隔符**周围**的空白，绝不改动值文本。
- **一元**符号（`-3`）、标识符或版本字符串中的 `-`，以及带引号字符串的内容，均不视为算术运算符。
