# Inno Setup 언어 파일

이 플러그인은 설치 프로그램 스크립트(`.iss`) 외에도 Inno Setup 언어 파일(`.isl`)을 지원합니다. 언어 파일은 스크립트와 동일한 편집기 인프라를 사용하지만 언어별 섹션만 유효합니다.

![Inno Setup 언어 파일 편집기](assets/images/isl.png)

---

## 지원되는 섹션

`.isl` 파일에는 다음이 포함될 수 있습니다:

- `[LangOptions]` — 언어 메타데이터, 로케일 식별자, 글꼴, 텍스트 방향
- `[Messages]` — 번역된 내장 설치 프로그램 메시지
- `[CustomMessages]` — `{cm:...}`을 통해 참조되는 번역된 프로젝트별 메시지

`.isl` 파일에는 `[Setup]`이 필요하지 않습니다. 대신 `[LangOptions]`가 `LanguageName`과 `LanguageID`를 정의해야 합니다.

---

## 편집 기능

### 구문 강조

`.iss` 파일에서 사용되는 것과 동일한 색상 구성표가 `.isl` 파일에도 적용됩니다:

- **섹션 헤더**(`[LangOptions]`, `[Messages]`, `[CustomMessages]`)가 구조적 마커로 강조 표시됨
- **지시문 키**와 해당 값이 각각 다른 색으로 표시됨
- **메시지 키**가 번역된 문자열 값과 구별되어 표시됨

### 코드 완성

`.isl` 파일 내에서 컨텍스트 인식 제안이 제공됩니다:

- 허용되는 값 유형을 가진 알려진 `[LangOptions]` 지시문 키
- **국기 아이콘**, 로케일 이름, 16진수 LCID와 함께 제공되는 `LanguageID` 값 — Inno Setup의 내장 언어가 목록 맨 위에 표시됨

### 인레이 힌트

`LanguageID` 값에 일치하는 **국기 아이콘과 로케일 이름**(예: *Dutch (Netherlands) $0413*)이 인라인으로 주석 처리되어 외부 문서에서 16진수 식별자를 찾아보지 않고도 언어를 즉시
알아볼 수 있습니다.

### 인라인 문서

`[LangOptions]` 키 위에 마우스를 올리면 번들된 사양에서 설명이 표시됩니다(허용되는 값과 비고 포함).

### 유효성 검사

주석 작성자가 `.isl` 파일의 문제를 강조 표시합니다:

- 알 수 없거나 철자가 잘못된 `[LangOptions]` 키
- 유효하지 않거나 인식되지 않는 `LanguageID` 값
- `[LangOptions]`에서 누락된 필수 지시문

### 언어 접두사 참조

메시지 키는 `.iss` 스크립트 내에서 사용될 때 `german.WelcomeLabel1`과 같은 언어 접두사를 가질 수 있습니다. 이러한 접두사는 `[Languages]`의 `Name:` 항목으로 해결되며 다음에
완전히 참여합니다:

- **정의로 이동** — 접두사에서 해당 `[Languages]` 선언으로 이동
- **사용 찾기** — 특정 언어 이름을 참조하는 모든 위치 찾기
- **이름 바꾸기 리팩터링** — 언어 이름을 바꾸고 접두사가 있는 모든 사용 위치를 일관되게 업데이트
