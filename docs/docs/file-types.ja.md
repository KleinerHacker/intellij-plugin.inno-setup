# ファイルタイプ

このプラグインは IntelliJ プラットフォーム内に 3 つの専用ファイルタイプを登録します。各ファイルタイプには独自のアイコン、言語インフラ、エディター機能セットがあります。

![Inno Setup ファイルタイプ](assets/images/filetypes.png)

---

## 概要

| ファイルタイプ               | 拡張子    | 用途                                   |
|-----------------------|--------|--------------------------------------|
| **Inno Setup スクリプト**  | `.iss` | メインインストーラー定義 — セクション、ファイル、レジストリ、コード  |
| **Inno Setup 言語ファイル** | `.isl` | 単一言語の翻訳メッセージとロケールオプション               |
| **Inno Setup テンプレート** | `.ist` | `#include` でスクリプトに取り込む再利用可能な自由テキスト断片 |

すべてのファイルタイプは拡張子によって自動認識されます。手動での関連付けは不要です。

---

## Inno Setup スクリプト（`.iss`）

`.iss` ファイルは Inno Setup のプライマリ形式です。パッケージ化するファイル、書き込むレジストリキー、提供する言語、そしてオプションとして
`[Code]` セクションの Pascal スクリプトランタイムロジックなど、完全なインストーラーを記述します。ISPP プリプロセッサーディレクティブ（
`#define`、`#include`…）はファイルの先頭に記述できます。

サポートされるセクションと編集機能の完全なリストは[スクリプトファイル](script-files.md)を参照してください。

---

## Inno Setup 言語ファイル（`.isl`）

`.isl` ファイルは単一のロケール向けに翻訳済み文字列を提供します。`.iss` スクリプトの `[Languages]` にある `MessagesFile:`
パラメーターから参照され、組み込みの Inno Setup メッセージの任意のサブセットをオーバーライドできます。プロジェクト固有のカスタムメッセージは
`[CustomMessages]` に配置することもできます。

サポートされるセクションと編集機能の完全なリストは[言語ファイル](language-files.md)を参照してください。

---

## Inno Setup テンプレート（`.ist`）

`.ist` ファイルは、ISPP の `#include`
ディレクティブを通じてスクリプトに取り込むことを意図した再利用可能な自由テキストの断片です。テンプレートはセクション全体、部分的なセクション、ばらばらのディレクティブ行、プリプロセッサー定義を保持できます。完全なインストーラーではなく構成要素にすぎないため、単独で検証されることはありません。その内容はホストの
`.iss`/`.isl` スクリプトに取り込まれて初めて解析されます。

完全な説明と編集機能については[テンプレートファイル](template-files.md)を参照してください。

---

## ファイルタイプ間の関係

`.iss` スクリプトは `[Languages]` セクションを通じて 1 つ以上の `.isl` ファイルを参照できます：

```ini
[Languages]
Name: "english"; MessagesFile: "compiler:Default.isl"
Name: "german";  MessagesFile: "compiler:Languages\German.isl"
```

プラグインはこれらの参照をファイル間で解決します：`[Languages]` で宣言された言語名は `[Messages]` および
`[CustomMessages]` 内の言語プレフィックス参照（例：`german.WelcomeLabel1`）のターゲットであり、スクリプト全体の値内の
`{cm:…}` 定数のターゲットでもあります。

`.iss`（または `.isl`）スクリプトは、さらに `#include` を通じて任意の数の `.ist` テンプレートを取り込めます：

```ini
#include "common-files.ist"
```

プラグインはインクルードを解決し、テンプレートのセクションをスクリプトの有効な（インクルード解決済みの）ビューにマージするため、共有された断片はインラインで書かれたかのように振る舞います。
