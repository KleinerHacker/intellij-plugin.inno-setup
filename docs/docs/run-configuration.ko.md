# 실행 구성

이 플러그인은 전용 **Inno Setup** 실행 구성 유형을 제공하여 IDE 내에서 `.iss` 스크립트를 컴파일하고 생성된 설치 프로그램을 즉시 실행할 수 있습니다.

---

## 실행 구성 만들기

프로젝트 뷰에서 **`.iss` 파일을 마우스 오른쪽 버튼으로 클릭**하고 **실행** 또는 **디버그**를 선택하면 실행 구성이 자동으로 생성됩니다. **실행 → 구성 편집…** 을 통해 수동으로 만들 수도
있으며, **+** 를 클릭한 후 **Inno Setup**을 선택하면 됩니다.

![Inno Setup 실행 구성](assets/images/run.png)

---

## 구성 옵션

| 옵션         | 설명                                                                              |
|------------|---------------------------------------------------------------------------------|
| **스크립트**   | 컴파일할 최상위 `.iss` 스크립트 경로. 드롭다운에는 프로젝트에서 찾은 모든 최상위 스크립트가 나열되며 경로를 직접 입력할 수도 있습니다. |
| **언어**     | 실행 시 설치 프로그램 언어를 선택합니다. 스크립트의 `[Languages]` 섹션에 두 개 이상의 항목이 있는 경우에만 표시됩니다.      |
| **디버그 출력** | 활성화하면 설치 프로그램에 `/DBGMSG`가 전달되어 설치 중 진단 메시지가 콘솔에 출력됩니다.                          |
| **빌드 구성** | 이 실행이 컴파일에 사용하는 이름 있는 컴파일 옵션 모음 — 전처리기 심볼, 출력 디렉터리 재정의, 추가 `ISCC` 옵션. 실행 구성에는 *이름*만 저장되며 옵션 자체는 [빌드 설정](settings-build.md)에 있습니다. 따라서 옵션을 수정하면 그 구성을 참조하는 모든 실행에 반영됩니다. 새 실행 구성은 **Debug**로 시작합니다. |

---

## 빌드 구성을 지정해 실행하기

빌드 구성은 실행 시 여전히 지정해야 하는 유일한 항목이므로, 모든 진입점에서 선택할 수 있습니다.

- `[Setup]` 섹션 옆의 **거터 아이콘**을 클릭하면 모든 빌드 구성 목록이 열리며, 선택한 구성으로 스크립트가 실행됩니다.
- `.iss` 파일의 **컨텍스트 메뉴**(프로젝트 뷰 또는 편집기)에서는 **스크립트 실행**과 **스크립트 빌드**가 하위 메뉴로 표시되며 각각 빌드 구성이 나열됩니다.
- 저장된 실행 구성은 **빌드 구성** 드롭다운에서 선택된 구성을 사용합니다.

참조된 빌드 구성이 삭제된 경우, 실행은 다른 구성으로 조용히 대체하지 않고 오류를 보고합니다.

---

## 편집기의 전처리기 심볼

편집기는 **선택된** 실행 구성이 참조하는 빌드 구성의 심볼로 `#ifdef` 분기를 판정합니다. 따라서 스크립트에서 흐리게 표시되는 내용은
다음 실행이 빌드할 내용과 일치합니다. 툴바에서 선택된 구성을 바꾸면 조건이 즉시 다시 평가됩니다.

선택된 Inno Setup 실행 구성이 없으면 스크립트 위에 배너가 표시됩니다 — 심볼을 공급할 수 없어 조건이 결정되지 않은 상태로 남습니다.
배너에는 기존 Inno Setup 실행 구성의 드롭다운이 포함되어 있어 그 자리에서 선택할 수 있습니다.

---

## 작동 방식

1. 스크립트가 ISCC로 컴파일됩니다([빌드 통합](build.md)과 동일한 파이프라인). 이때 선택된 빌드 구성의 `/D` 심볼과 추가 옵션이 함께 전달됩니다.
2. 프로젝트 출력 모드가 **드라이 빌드**로 설정된 경우, 플러그인이 자동으로 출력을 임시 디렉토리로 리디렉션하여 실제 설치 프로그램을 생성하고 실행할 수 있도록 합니다.
3. 생성된 `setup.exe`가 실행되며, 프로세스 출력이 **실행** 도구 창에 스트리밍됩니다.

빌드는 참여 파일, 출력 위치 **그리고** 빌드 구성의 내용이 마지막 성공한 빌드 이후 모두 변경되지 않은 경우에만 재사용됩니다.
