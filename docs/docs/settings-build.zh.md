# 构建设置

**构建**子页面位于 IDE 设置中的**构建、执行、部署 → Inno Setup → 构建**下。

![Inno Setup 构建设置](assets/images/settings_build.png)

这些设置是**项目范围**的（按项目存储，而非全局）。

---

## 构建

| 选项                  | 说明                                           |
|---------------------|----------------------------------------------|
| **项目构建时编译 .iss 文件** | 启用后，每次构建项目时，项目中所有顶级 `.iss` 脚本都会使用 `ISCC` 编译。 |
| **输出**              | 控制编译后的安装程序输出位置。请参阅下方的值。                      |

**输出值**

| 值                   | 说明                                                     |
|---------------------|--------------------------------------------------------|
| **按脚本定义**           | 保持脚本的 `[Setup] OutputDir` 不变——不向 `ISCC` 传递 `/O` 开关。    |
| **输出到项目构建目录**（*默认*） | 将相对 `OutputDir` 重定向到项目构建文件夹（`out`/`target`/`build`）下方。 |
| **空构建——仅验证，无输出**    | 传递原生 `ISCC` `/O-` 开关，使脚本得到验证但不产生安装程序文件。                |

---

## 构建配置

**构建配置**是 Inno Setup 中相当于 C/C++ 构建配置的概念：一组具名的编译选项，[运行配置](run-configuration.md)按名称引用它。
选项集中存放，因此多个运行可以共享它们，修改一次即可在所有引用处生效。

| 选项              | 说明                                                                    |
|-----------------|-----------------------------------------------------------------------|
| **预处理器符号**      | 以 `/D` 传递给编译器的符号，例如 `DEBUG` 或 `VERSION=2`；多个符号用逗号、分号或空格分隔。            |
| **输出目录**        | 覆盖安装程序的写入位置。相对路径会解析到项目构建文件夹下方。留空则沿用上方的**输出**规则。                        |
| **附加 ISCC 选项**  | 其他原始 `ISCC` 命令行选项，以空格分隔。包含空格的值请用双引号括起来。                               |

使用**添加**、**复制**、**重命名**和**删除**管理列表。至少必须保留一个配置。

### 默认值

尚未拥有构建配置的项目会以两个配置开始：

| 名称          | 符号      | 用途                |
|-------------|---------|-------------------|
| **Release** | *（无）*   | 不定义任何符号的普通构建。     |
| **Debug**   | `DEBUG` | 每个新建运行配置的默认值。     |

### 存储

每个配置都作为**项目 `.build` 目录中的单个文件**存储，与 `.idea` 并列——与平台在 `.run` 中存放可共享运行配置的布局相同。
每个配置一个文件便于审阅与合并，因此可以通过版本控制与团队共享。

### 对构建的影响

所选构建配置的内容属于构建的最新性检查。因此，将运行从 `Debug` 切换到 `Release`，或仅仅修改 `Debug` 的符号，
都会使先前生成的安装程序失效并触发重新构建。重命名配置则不会——名称不属于被编译的内容。
