# 构建设置

**构建**子页面位于 IDE 设置中的**构建、执行、部署 → Inno Setup → 构建**下。

![Inno Setup 构建设置](assets/images/settings_build.png)

这些设置是**项目范围**的（按项目存储，而非全局）。

---

## 构建

| 选项                  | 说明                                           |
|---------------------|----------------------------------------------|
| **项目构建时编译 .iss 文件** | 启用后，每次构建项目时，项目中所有顶级 `.iss` 脚本都会使用 `ISCC` 编译。 |
| **输出**              | 控制编译后的安装程序输出位置。请参阅下方的值。                      |

**输出值**

| 值                   | 说明                                                     |
|---------------------|--------------------------------------------------------|
| **按脚本定义**           | 保持脚本的 `[Setup] OutputDir` 不变——不向 `ISCC` 传递 `/O` 开关。    |
| **输出到项目构建目录**（*默认*） | 将相对 `OutputDir` 重定向到项目构建文件夹（`out`/`target`/`build`）下方。 |
| **空构建——仅验证，无输出**    | 传递原生 `ISCC` `/O-` 开关，使脚本得到验证但不产生安装程序文件。                |
