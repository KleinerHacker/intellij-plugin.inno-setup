# 运行配置

该插件提供专用的 **Inno Setup** 运行配置类型，可在 IDE 内编译 `.iss` 脚本并立即启动生成的安装程序。

---

## 创建运行配置

在项目视图中**右键点击 `.iss` 文件**并选择**运行**或**调试**时，运行配置会自动创建。也可以通过**运行 → 编辑配置…**手动创建，点击
**+**，然后选择 **Inno Setup**。

![Inno Setup 运行配置](assets/images/run.png)

---

## 配置选项

| 选项       | 说明                                             |
|----------|------------------------------------------------|
| **脚本**   | 要编译的顶级 `.iss` 脚本路径。下拉列表列出项目中所有顶级脚本，也可直接输入路径。   |
| **语言**   | 启动时选择安装程序语言。仅当脚本的 `[Languages]` 节包含两个或更多条目时显示。 |
| **调试输出** | 启用后，向安装程序传递 `/DBGMSG`，以便在安装过程中将诊断消息打印到控制台。     |
| **构建配置** | 本次运行所使用的一组具名编译选项——预处理器符号、输出目录覆盖以及附加 `ISCC` 选项。运行配置中只保存其*名称*；选项本身位于[构建设置](settings-build.md)，因此修改它们会在所有引用该配置的运行中生效。新建的运行配置默认使用 **Debug**。 |

---

## 使用构建配置运行

由于构建配置是运行时唯一还需要指定的内容，每个入口都提供选择：

- `[Setup]` 节旁的**装订线图标**会打开所有构建配置的列表，选择其一即可用它运行脚本。
- `.iss` 文件的**上下文菜单**（项目视图或编辑器）将**运行脚本**与**构建脚本**显示为子菜单，其中列出各个构建配置。
- 已保存的运行配置使用其**构建配置**下拉框中所选的配置。

如果被引用的构建配置已被删除，运行会报告错误，而不会悄悄回退到其他配置。

---

## 编辑器中的预处理器符号

编辑器使用**当前选中**的运行配置所引用的构建配置的符号来判定 `#ifdef` 分支，因此脚本中被淡化的内容与下一次运行构建的结果一致。
在工具栏中切换所选配置会立即重新求值这些条件。

若未选中任何 Inno Setup 运行配置，脚本上方会出现提示横幅——此时无法提供符号，条件将保持未确定。
横幅中包含现有 Inno Setup 运行配置的下拉框，可直接在此完成选择。

---

## 工作原理

1. 脚本通过 ISCC 编译（与[构建集成](build.md)管道相同），并带上所选构建配置的 `/D` 符号与附加选项。
2. 如果项目的输出模式设置为**空构建**，插件会自动将输出重定向到临时目录，确保生成真实的安装程序并可启动。
3. 生成的 `setup.exe` 被执行，其进程输出实时流式传输到**运行**工具窗口。

只有当参与的文件、输出位置**以及**构建配置的内容自上次成功构建以来均未改变时，才会复用已有构建。
