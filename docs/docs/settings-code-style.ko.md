# 코드 스타일

플러그인은 **코드 재정렬**(<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>L</kbd>)로 `.iss` / `.isl` 스크립트를 정렬합니다.
규칙은 **설정 ▸ 편집기 ▸ 코드 스타일 ▸ Inno Setup** 에 있으며 기본적으로 모두 활성화되어 있습니다.

---

## 규칙

| 규칙                          | 효과                                                | 예시                                        |
|-----------------------------|---------------------------------------------------|-------------------------------------------|
| **섹션 사이에 정확히 한 줄의 빈 줄** | 두 `[Section]` 블록 사이의 간격을 빈 줄 하나로 축소(또는 삽입)합니다. | `…value`⏎⏎⏎`[Files]` → `…value`⏎⏎`[Files]` |
| **섹션 대괄호 안에 공백 없음** | 섹션 이름 주위의 대괄호를 붙입니다.                        | `[ Setup ]` → `[Setup]`                   |
| **지시문의 `=` 양쪽에 공백** | `Key = Value` 지시문의 `=` 양쪽에 공백을 하나씩 둡니다.     | `AppName=My App` → `AppName = My App`     |
| **매개변수의 `:` 뒤에 공백** | `Key: Value` 매개변수의 `:` 앞은 비우고 뒤에 공백 하나를 둡니다. | `DestDir:"{app}"` → `DestDir: "{app}"`    |
| **매개변수 사이 `;` 뒤에 공백** | 매개변수 쌍을 구분하는 `;` 앞은 비우고 뒤에 공백 하나를 둡니다.    | `"a" ;DestDir` → `"a"; DestDir`           |
| **키 앞에 선행 공백 없음**   | 키 / 매개변수 / 섹션 머리글 줄이 0열에서 시작합니다.          | `····AppName = A` → `AppName = A`         |
| **산술 연산자 양쪽에 공백**  | 전처리기 식의 `+ - * / %`(이항 연산자만) 양쪽에 공백을 둡니다.  | `#define X 2+3*4` → `#define X 2 + 3 * 4`  |

각 규칙은 설정 페이지에서 개별적으로 끌 수 있습니다. `=`, `:`, `;`, 대괄호, 선행 공백 옵션은 **간격(Spacing)** 아래에,
빈 줄 옵션은 **빈 줄(Blank Lines)** 아래에 있습니다.

---

## 변경되지 않는 부분

- **`[Code]`** 섹션(Pascal Script)과 그 이후의 모든 내용 — 들여쓰기와 레이아웃이 보존됩니다.
- 값 자체 — 구분자 **주위**의 공백만 정규화하며 값 텍스트는 절대 변경하지 않습니다.
- **단항** 부호(`-3`), 식별자나 버전 문자열 안의 `-`, 따옴표 문자열의 내용은 산술 연산자로 취급하지 않습니다.
