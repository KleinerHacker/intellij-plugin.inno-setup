# エディター設定

**Inno Setup** 設定ノードの**エディター**サブページでは、`.iss` スクリプトをエディターでどのように表示するかを制御します。

![Inno Setup エディター設定](assets/images/settings_editor.png)

---

## インレイヒント

| オプション                         | 説明                                                                                                                                                      |
|-------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| **#include の内容をインレイヒントとして表示** | `#include "…"` ディレクティブの解決済みの内容を、その行の**下**にインレイヒントとして表示し、インクルードファイルの改行を保持します。ヒントをクリックするとインクルードファイルへジャンプします。ファイルが見つからない、または読み取れない場合はヒントを表示しません。**既定で有効。** |

これらの設定は **IDE 全体**のものです（グローバル IDE 設定に保存され、プロジェクトごとではありません）。

**`#define` の計算結果** のヒントはここには含まれません。プラットフォームの宣言的インレイ API を使用しているため、
他のすべてのインレイヒントと同様に **Settings | Editor | Inlay Hints** で切り替えます。表示内容については
[`#define`](preprocessor/define.ja.md) を参照してください。
