# 設定

このプラグインは IDE の設定（Windows/Linux では**ファイル → 設定**、macOS では **IntelliJ IDEA → 設定**）の**ビルド、実行、デプロイ**に **Inno Setup** ノードを追加します。

---

## Inno Setup のインストール

![Inno Setup 設定](assets/images/settings.png)

| オプション               | 説明                                                                             |
|--------------------------|----------------------------------------------------------------------------------|
| **インストールディレクトリ** | Inno Setup インストールフォルダーへのパス。`ISCC.exe` と `Compil32.exe` が含まれている必要があります。 |
| **検出されたバージョン** | 選択されたディレクトリで見つかった Inno Setup バージョンを表示する読み取り専用フィールド。 |

### バージョン検証

| オプション                     | 説明                                                                                                                     |
|--------------------------------|--------------------------------------------------------------------------------------------------------------------------|
| **最小 Inno Setup バージョン** | 使用可能なバージョンオプションを検出されたメジャーバージョンに制限します。`.iss` ファイルのバージョン対応の警告に使用されます。 |

これらの設定は **IDE 全体**のものです（グローバル IDE 設定に保存され、プロジェクトごとではありません）。
