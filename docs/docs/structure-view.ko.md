# 구조 뷰

이 플러그인은 `.iss` 스크립트 파일에 완전히 통합된 구조 뷰를 제공합니다. **구조** 도구 창(**Alt+7**) 또는 **탐색 → 파일 구조** 팝업(**Ctrl+F12**)을 통해 접근할 수 있습니다.

![Inno Setup 구조 뷰](assets/images/structure.png)

---

## 트리 레이아웃

구조 트리는 스크립트의 논리적 구성을 반영합니다:

- **루트 노드**는 `.iss` 파일 자체를 나타냅니다(스크립트 파일 아이콘으로 표시).
- **섹션 노드**(예: `[Setup]`, `[Files]`, `[Languages]`)는 루트의 직접 자식으로 각각 섹션 아이콘과 함께 표시됩니다.
- **항목 노드**는 섹션의 자식으로 섹션 유형에 따라 개별 지시문, 매개변수 항목 또는 메시지 키를 나타냅니다.

---

## 탐색

구조 뷰에서 노드를 클릭하면 편집기 커서가 해당 줄로 직접 이동합니다. 이렇게 하면 큰 스크립트에서 스크롤 없이 떨어진 섹션 간을 쉽게 이동할 수 있습니다.

편집기에서 커서가 이동하면 구조 뷰가 **자동 스크롤**하여 현재 위치를 포함하는 항목을 강조 표시하고 트리와 편집기를 항상 동기화합니다.

---

## 항목 아이콘

각 항목에는 해당 종류를 나타내는 아이콘이 표시됩니다:

| 아이콘 | 의미                             |
|-----|--------------------------------|
| `f` | 필드형 항목 — 값을 가진 지시문 키 또는 매개변수 키 |
| `C` | 섹션 컨테이너 노드                     |

루트 노드의 파일 형식 아이콘은 IDE 전체에서 사용되는 `.iss` 파일 아이콘과 일치합니다.

---

## 탐색 경로 표시줄

편집기 하단의 상태 표시줄에 현재 커서 위치의 **구조 경로**(예: `demo.iss › [Setup] › DefaultGroupName`)가 표시되어 구조 도구 창을 열지 않고도 항상 방향을 파악할 수 있습니다.

---

## 고정 줄

동일한 구조 정보가 편집기의 **고정 줄**에도 사용됩니다. 현재 섹션의 헤더(`[Setup]`, `[Files]` 등)가 스크롤되어 화면에서 사라지면 편집기 상단에 고정되므로, 보이는 항목이 어느 섹션에 속하는지 항상 알 수 있습니다. 고정된 줄을 클릭하면 해당 줄로 돌아갑니다.

개별 항목은 고정되지 않습니다 — 한 줄짜리라 방향 파악에 도움이 되지 않기 때문입니다. 전처리기 블록(`#if …`, `#sub …`)도 고정되지 않습니다. 스크립트 문법에 블록 전체를 포괄하는 요소가 없기 때문입니다.
