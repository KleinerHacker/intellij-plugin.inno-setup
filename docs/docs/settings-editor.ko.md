# 편집기 설정

**Inno Setup** 설정 노드의 **편집기** 하위 페이지는 `.iss` 스크립트가 편집기에 표시되는 방식을 제어합니다.

![Inno Setup 편집기 설정](assets/images/settings_editor.png)

---

## 인레이 힌트

| 옵션                                  | 설명                                                                                                                                                |
|---------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| **#include 내용을 인레이 힌트로 표시** | `#include "…"` 지시문의 해석된 내용을 해당 줄 **아래**에 인레이 힌트로 표시하며 포함된 파일의 줄바꿈을 유지합니다. 힌트를 클릭하면 포함된 파일로 이동합니다. 대상 파일을 찾을 수 없거나 읽을 수 없으면 힌트가 표시되지 않습니다. **기본적으로 활성화됨.** |

이 설정은 **IDE 전역**입니다(전역 IDE 구성에 저장되며 프로젝트별이 아님).

---

## 일반 설정
