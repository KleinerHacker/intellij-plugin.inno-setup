# 构建集成

该插件将 Inno Setup 的命令行编译器 **ISCC** 直接集成到 IDE 中，让您无需离开编辑器即可编译 `.iss` 脚本。使用任何构建功能之前，请确保在**构建、执行、部署 → Inno Setup → 常规**下配置了 Inno Setup 安装目录（参见[设置](settings.md)）。

---

## 触发构建

### 右键菜单操作

在项目视图或编辑器选项卡中右键点击任意 `.iss` 文件，选择 **Build Inno Setup Script**。该操作仅对 `.iss` 文件可见，对通过 `#include` 被其他脚本包含的脚本禁用（带有解释性工具提示）——这类文件必须通过其顶级父文件构建。

### 项目构建时自动构建

在[构建设置](settings-build.md)中启用**项目构建时编译 .iss 文件**后，每次 IDE 构建项目时（例如通过**构建 → 构建项目**或锤子图标），项目中所有顶级 `.iss` 脚本都会自动编译。被其他脚本包含的脚本会自动跳过。

## 构建输出控制台

![Inno Setup 构建输出](assets/images/build.png)

构建结果显示在**构建**工具窗口下的专用 **Inno Setup** 节点中。每个编译的脚本都有其自己的子节点，显示其名称和错误或警告数量。

### 控制台输出

右侧面板逐行显示原始 ISCC 输出——进度消息、节解析说明和任何编译器诊断信息：

| 行类型      | 外观              | 示例                                                              |
|-------------|-------------------|-------------------------------------------------------------------|
| **进度**    | 普通白色文本      | `Parsing [Files] section, line 22`                                |
| **错误**    | 红色文本          | `Error on line 22 in C:\...\demo.iss: Source file "..." not found` |
| **警告**    | 黄色文本          | `Warning on line 5 in C:\...\demo.iss: ...`                       |

### 可导航的错误链接

包含文件位置的错误和警告行包含可点击的 **`line XX`** 超链接。点击它可打开引用的 `.iss` 文件，并将光标直接移动到报告的行和列，让您无需手动搜索脚本即可修复问题。

### 构建树

构建工具窗口左侧的树汇总了结果：

- 脚本节点上的**红色错误图标**表示至少有一个编译器错误。
- **黄色警告图标**表示有警告但无错误。
- 单个问题条目列为子节点；点击一个可导航到源位置。

## 输出模式

编译后的安装程序的输出位置可通过[构建设置](settings-build.md)按项目控制：

| 模式                                       | ISCC 标志 | 说明                                                                      |
|--------------------------------------------|-----------|---------------------------------------------------------------------------|
| **按脚本定义**（*script*）                 | *（无）*  | 使用 `[Setup]` 中的 `OutputDir` 不变                                      |
| **输出到项目构建目录**（*default*）         | `/O`      | 将相对 `OutputDir` 重定向到项目的构建文件夹（`out`/`target`/`build`）     |
| **空构建——仅验证，无输出**                 | `/O-`     | 验证脚本但不生成安装程序文件；适用于 CI 检查                              |
