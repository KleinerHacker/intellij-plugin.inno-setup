IsSectionDirectiveEntryEx

interface IsSectionDirectiveEntryEx : PsiNameIdentifierOwner

Extra behaviour for Key=Value directive entries. A directive entry in the \[CustomMessages] section declares a custom message and acts as a renamable PsiNameIdentifierOwner whose name is the message identifier (the part after any optional lang. prefix).
