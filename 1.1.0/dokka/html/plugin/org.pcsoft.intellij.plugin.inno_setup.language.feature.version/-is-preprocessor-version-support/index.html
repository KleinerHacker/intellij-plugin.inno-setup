IsPreprocessorVersionSupport

object IsPreprocessorVersionSupport

Shared version logic for ISPP directives, built-in functions and predefined variables.

It compares the since/until values of the preprocessor specification with the configured minimum Inno Setup version. It lives in the plugin module because the minimum version is a script-module setting, which the independent preprocessor module must not know about.
