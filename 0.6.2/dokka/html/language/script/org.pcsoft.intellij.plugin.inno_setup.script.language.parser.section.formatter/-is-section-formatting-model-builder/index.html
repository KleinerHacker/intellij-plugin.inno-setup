IsSectionFormattingModelBuilder

class IsSectionFormattingModelBuilder : FormattingModelBuilder

Enables Reformat Code for Inno Setup .iss/.isl files. The whole file is exposed as a single opaque leaf block, so the model itself never rewrites whitespace — that would be unsafe given line breaks are real CRLF tokens and the [Code] section is free-form Pascal Script. All actual formatting (bracket, =, :, ; spacing, blank lines, leading-key trimming and preprocessor operator spacing) is performed with precise, PSI-guided edits by IsFormatterPostFormatProcessor, which the reformat pipeline runs right after this (no-op) model pass.
